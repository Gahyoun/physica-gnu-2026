### Deliberate additions and source quirks

- Photoelastic measurement apparatus originally displays configuration and view controls. Its native transmission numeric readout is an explicitly labeled Jones-model explanation, not an original numeric output.
- Original liquid-crystal geometry uses random placement. Native geometry uses a fixed seed with the original distribution. Original nematic repeated same-state remakes can drift; native redraw is idempotent and preserves the alternating field states.
- Native lattice selected mass, history graph, CSV, playback controls and finite600step viewing window are additions. Step0 evaluates the original motion formula at phase0; the original initial pre-timer frame has anchor positions until its first0.5phase callback.
- Original birefringence angle slider construction uses decimal-digit mode. Actual runtime establishes angle increments0.1° for both optic-axis and incidence controls; these were corrected before validation.
- The wave-direction theta readout reproduces the original extraordinary walk-off calculation even while the ordinary mode is selected. It does not imply ordinary-wave walk-off.
- New refraction diagrams keep original vector coordinates and rounded readout arithmetic but use fresh vector primitives and theme colors, not original drawings.

No original code exports or private diagnostic SWFs are distributed. Private extracted sources and tools remain in ignored preview paths.
