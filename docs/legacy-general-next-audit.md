# 일반 물리 Java 추가 복원 감사

2026-10-10. 기존 일반 물리 17종에 파동·음향 11종과 열역학 21종을 추가하여 49종입니다. Java 실행 코드 47종과 기존 HTML/p5 모델 2종을 구별합니다. `manyCol23`은 이름이 같아도 `kineticgas21`의 2차원 경질 입자와 `kineticgas23`의 3차원 피스톤 실린더를 독립 실행 코드로 다룹니다.

## 근거와 대조 범위

- `src/legacy-general.json`의 원본 클래스 URL, 코드베이스, SHA-256과 실제 GUI 경계를 기록했습니다. 원본 클래스와 CFR 분석 사본은 개인 임시 캐시에 있으며 배포하지 않습니다. 기존 URL의 Doppler JAR 위치가 틀려 실제 `applets/sound/doppler.jar`에서 확보했습니다.
- 원본 AWT/Swing을 실제 실행한 `docs/legacy-original-gui-report.json`에서 새 32종 모두 초기화 및 조작 기록을 확보했습니다. 28종은 해당 GUI 프로브 범위 내 통과, Beat1·Syndi1·3D 피스톤 manyCol23·3D 상자 manyCol31은 원본의 초기화/스레드/렌더링 오류로 일부 검증입니다. 원본의 오류를 현대 모델 성공으로 덮어쓰지 않습니다.
- `tools/legacy-general-reference/GeneralFormulaProbe.java`는 원본 JVM bytecode 메서드를 직접 호출합니다. `waveform1.Wave.getValue` 432값(8파형×3주파수×3진폭×6시간)과 `VWpotential.ballPotential` 252값(2종 퍼텐셜×7전하곱×3반지름합×6거리)을 `docs/legacy-general-next-oracle.json`에 보존했습니다. 음전하, 무전하, 접촉 전후를 포함합니다. 단위/정규화의 특이점도 원본대로 유지합니다.
- `tools/legacy-general-next.test.mjs`는 위 수치, 쌍힘의 반대칭, 2D/3D 충돌의 에너지·운동량 보존, 충돌 시간 근, FFT 원본 스케일, 각 모델 슬라이더 경계와 유한 선택 조합을 검사합니다. 기존·새 모델 합계 87개 테스트를 통과했습니다. MIDI는 채널×프로그램×체크박스 65,536개의 수치 상태를 확인합니다. 연속 입력의 모든 실수를 조사했다는 뜻은 아닙니다.
- `docs/legacy-general-next-ui-report.json`: Chromium에서 새 32종을 직접 마운트하여 재생·일시정지·리셋, 각 슬라이더 양끝, 모든 개별 선택값, 체크박스의 유한 조합을 조작했습니다. 푸리에·스펙트럼은 정적인 입력/결과 도구이므로 재생바가 없습니다. 브라우저 선택 메뉴의 전체 곱과 수치 모델의 전체 곱 검사는 별도로 구분합니다.

## 아직 동일하다고 주장하지 않는 부분

1. 무작위 초기 상태는 반복 가능한 시드를 쓰므로 원본 Math.random의 개별 궤적과 같지 않습니다. 원본의 열적 평형·충돌 통계에 대한 장시간 출력 전수 비교와 임의 마우스 궤적/조작 순서 검증은 남아 있습니다.
2. 현대 컨트롤을 변경하면 재현 가능한 처음 상태로 다시 계산합니다. 원본 일부 도구의 실행 도중 매개변수 변경 및 자동 푸리에 더함 순서와 완전히 같은 GUI 상태 기계라고 주장하지 않습니다. 정적 푸리에 도구는 명시적인 차수 입력으로 대체했습니다.
3. MIDI의 Java 네이티브 음원은행은 확보하지 못했습니다. WebAudio 파형은 소리의 대체이며 128개 GM 음색의 동일 재현이 아닙니다. Pressure/Reverb/Solo/Mono의 완전한 청각 행동 비교도 미완료입니다. 기타·피아노는 원본 배음 수식이지만 PCM 16비트 양자화와 장치별 재생 품질은 다릅니다.
4. 음원 간섭장은 원본의 지연시간 장 수식을 사용합니다. WebAudio는 브라우저 출력이고 원본 스테레오 장치 재생의 좌·우 채널 청각 대조는 수행하지 않았습니다. 노이즈 생성기는 재현 가능한 가우스 표본이지만 Java Random과 표본별 일치는 아닙니다.
5. 수치 기준 증거 684개는 파형·퍼텐셜 메서드에 대한 직접 대조입니다. 모든 프로그램의 모든 출력이 684개 증거로 보장되지는 않습니다. 새 열역학 모델의 시간 스케줄·모든 thermostat 호출 순서·이벤트 배열 캐시·장시간 통계는 원본 런타임과 추가 비교가 필요합니다. 3D 실린더의 과밀 조건은 원본의 용적 확장 규칙을 사용하며 계산 충돌 제한에 도달하면 안내합니다.
6. 다중 차원의 연속 입력 조합은 무한합니다. 유한 선택과 경계·코너를 검사한 범위 밖을 완료로 표시하지 않습니다.

곡선은 alpha 0.65, GNU 파랑·회색 중심입니다. 보이지 않는 모델/숨겨진 탭은 정지하고, 큰 입자계의 프레임당 계산 횟수를 제한합니다. 원본 소유·출처는 유지하며 원본 재생과 현대 계산 도구를 별도로 보존합니다.
