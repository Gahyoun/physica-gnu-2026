# 수식 컴파일 및 화면 점검

2026-10-10. 본문뿐 아니라 자료 제목과 원본 링크에도 동일한 수식 컴파일을 적용했다. 핵반응 제목 `(α,p)`·`(n,γ)`가 `$…$` 원문으로 출력되던 경로를 수정했고, 설명문 안의 `ξ=x−vt`, `v=λ/τ`, `dS=δQ/T`도 인라인 LaTeX로 작성했다. 제목에 남아 있던 수집용 `__h__` 표시는 화면에서 제거했다. 검색과 접근성 이름은 Greek 문자·아랫첨자가 있는 평문을 사용한다.

수식은 빌드에서 KaTeX로 HTML과 MathML을 함께 생성한다. `\(…\)`·`$…$`, `\[…\]`·`$$…$$`를 처리하며 일반 문자열은 HTML로 해석하지 않고 escape한다. 잘못된 명령은 빌드 오류로 처리한다. 브라우저에서 외부 CDN이나 추가 수식 엔진을 다운로드하지 않는다.

애니메이션 아래 수식은 별도 `math.css`에서 컨테이너 안의 가로 스크롤과 왼쪽 정렬을 적용해 모바일에서 첫 항을 잃지 않고 끝까지 읽을 수 있도록 했다. 키보드로도 컨테이너에 초점을 둘 수 있다. 정적 줄의 장력 도식도 그림 안에서 좌우로 탐색하며 문서 자체가 늘어나지 않는다. 공통 애니메이션 재생 CSS 및 물리 계산은 변경하지 않았다.

[실제 수식 화면 검사](math-ui-report.json)는 수식이 있는 571페이지를 320/768/1360px에서 검사한 1,713건이다. JavaScript를 끄고 서체가 로딩된 뒤 KaTeX 오류, annotation 밖의 원시 LaTeX, 기호의 컨테이너 경계, 긴 수식의 내부 스크롤과 문서 가로 넘침을 확인했다. 모든 사례가 통과했다. 모바일 분수·행렬과 핵반응 제목의 실제 화면도 눈으로 확인했다.

이 검사는 컴파일 및 표시 검증이다. 수식 자체의 물리적·수학적 정확성을 새로 전수 검증했다는 뜻은 아니다. 원본 정정·기존 물리 단위검사는 별도 기록을 따른다. 애니메이션 SVG의 축·수치 라벨은 이 KaTeX 검사 대상과 구별한다.

## 2026-11-02 화면 구성 변경 후 재검사

GNU·KRDS 정보 배치로 공통 헤더와 홈 목차를 정리한 뒤 `tools/math-browser-check.mjs`를 로컬 Chrome에서 다시 실행했다. 수식이 있는 571페이지를 320/768/1360px로 열어 총 1,713건을 확인했으며 모두 통과했다. JavaScript를 끄고 폰트와 새 `assets/site-layout.css`가 실제로 로딩된 상태에서 KaTeX 오류, 화면에 노출된 원시 LaTeX, 수식 컨테이너 경계, 긴 수식의 내부 스크롤과 문서 가로 넘침을 검사했다. 1360px 화면 기준 컴파일된 수식 요소는 2,974개다.

이번 정식 JSON 보고서는 새 레이아웃 CSS와 검사기 자체를 포함한 의존성의 SHA-256을 기록하고 실행 시작·종료 사이에 파일이 바뀌지 않았는지도 확인한다. 예전 보고서의 해시만 바꾼 갱신이 아니다. 이 결과는 수식의 컴파일·읽기 화면 검증이며 애니메이션 조작·수치 모형의 정확성·원본과의 완전 동등성을 새로 검증한 기록은 아니다. 다른 애니메이션 검증 보고서는 갱신하지 않았다.
