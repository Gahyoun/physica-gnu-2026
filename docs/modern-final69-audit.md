# Final 69: 현대물리 21개 리마스터 검증 기록

21개 원본을 새로운 HTML 조작과 SVG 형상으로 구현했다. 원본 그림 프레임이나 Ruffle 화면을 리마스터 출력으로 복사하지 않는다. Compton의 120프레임×2객체×6변환값은 원본 nested 태그의 독립 비트 디코더로 전부 대조한다. 원저자의 계산·단위·배치를 참고하되 파랑·회색, 그래프 불투명도 0.65, 회색 구조물로 표시한다.

## 결과와 재현

- 독립 원본 소스 VM 대조: 21개, **183,464개 수치/문자 비교 통과** (`modern-final69-source-report.json`). 원본의 별도 수치 클래스와 초기화 루틴을 독립 컴파일해 포텐셜·고유에너지·파동함수·운동 궤적·원소 데이터·조작 변경을 비교한다.
- 실제 원본 Ruffle 런타임 대조: 21개, **2,274개 비교 통과** (`modern-final69-runtime-report.json`). 원본 ABC, 문서 클래스, Timer와 원본 태그 바이트를 보존한다. 사설 메모리 route에 읽기 전용 관측기만 추가하며 실제 버튼은 포인터로 누른다. 원본 업데이트 함수를 강제 호출하지 않는다.
- 단위 검사: **16개 통과**, private 추출 파일 없이 실행 가능 (`node --test tools/modern-final69.test.mjs`).
- 실제 읽기 페이지 UI: 320 / 768 / 1360px의 63개 케이스를 `modern-final69-browser-check.mjs`로 검증한다. 최종 결과는 대응 JSON의 각 `passed`와 현재 해시로 확인한다.

## 원본 조작과 표현의 보강

원소별 표·결정·반도체 화면은 각각의 원본 데이터와 개별 원소 위치를 사용한다. 빈 원소 이름을 가진 원본 결정 항목은 표시하지 않는다. 스펙트럼은 원본 Rodrigues 투영, 광원 상자와 격자, 양쪽 스펙트럼 띠를 새 polygon으로 구현했다. 정적 화면 6개에는 재생 버튼이나 프레임 막대를 두지 않는다.

결합·속박·불순물의 서로 다른 원본 수치 모형을 Worker에서 계산한다. 각 퍼텐셜과 에너지 준위, 파동함수 또는 두 입자의 운동을 연결한다. 원본 쌍둥이 시간과 기록 그래프는 같은 계산 단계에서 그린다. 동시성 화면은 원본 11×9개의 시계 격자를 새 SVG로 구성한다. Compton은 원본의 광자와 자유전자 한 개를 사용하며 잘못된 원자핵 표현을 제거했다.

Franck–Hertz는 250개 전자와 전류·전압 그래프를 함께 그린다. 수동 전압·필라멘트·기체 변경은 기존 전자 상태를 유지하며 자동 추적을 해제한다. 자동 추적을 시작하면 원본처럼 전압 0에서 재생한다. 원본 OListener의 실시간 입력 3회와 1,500단계 독립 소스 대조를 포함한다. CSV는 배열/객체 값을 인용하며 수치 격자 CSV는 열 수를 일정하게 유지한다.

동적 화면 15개는 아래쪽 계산 막대, 기본 빠른 재생과 느리게 옵션, 화면 밖/숨긴 탭 일시 정지, 입력 계산 상태를 갖춘다. 좁은 화면에서는 상세 SVG를 가로 탐색할 수 있어 작은 글씨로 축소하지 않는다. 색은 테마 변수로 받아 다크 모드에도 맞춘다.

## 대조 범위와 한계

이 보고서는 모든 연속 입력 조합의 전수 동등성을 주장하지 않는다. `fullEquivalence: false`를 유지한다. 소스 대조와 실제 런타임 대조는 별도의 증거다.

원본의 난수 상태는 cavity / Franck–Hertz / 속박 입자 / 별 / 시계에서 최초 공개값 한 번만 읽어 초기 상태를 맞춘다. 이후 프레임을 복사하지 않는다. 실제 Franck–Hertz 런타임은 관측 구간 중 무작위 굴절·경계·비탄성 충돌을 제외한 전자를 독립 예측한다. 전체 250개 전자의 충돌 계산과 실시간 수동 조작은 별도 소스 VM에서 검증한다. cavity 런타임은 다음 무작위 반사 전의 자연 전진, 원본 반사법칙은 소스에서 검증한다.

속박 입자 런타임은 원본 임의 모드에 맞춘 에너지·포텐셜을 검증하며, 공개 tick이 없어 원본 운동의 시점 일치는 런타임 증거에 포함하지 않는다. 원본 시간 단계의 운동은 독립 소스 검증에 포함한다. 결합·불순물 런타임은 기본 원본 에너지/공개 상태를 관측하고 다른 입력과 파동함수는 소스 대조에 포함한다.

equivalence / lightpath는 원본 표시 속성의 매 단계 1/20픽셀 양자화를 반영한 누적 표시 오차 범위를 사용한다. 최대 실제 관측 오차는 각 JSON `maxAbsoluteError`에 기록하며 0으로 대체하지 않는다. 시계 격자 런타임은 대표 시계 손의 자연 회전 5개 프레임을 관측한다. 전체 입력 조합, 임의 초기 상태와 장시간 반복은 추가 검증 영역이다.
