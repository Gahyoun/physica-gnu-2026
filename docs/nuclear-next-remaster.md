# 핵물리 개별 리마스터 — 추가 8개

정기수 교수님의 원본 모형을 개별 HTML/SVG로 다시 구현했다. 원본 SWF와 ActionScript는 변경하지 않는다. 원본 애니메이션은 별도의 Ruffle 페이지에서 비교한다.

## 구현과 검증

- 핵반응 4개: 알파 반응, 포획 반응, 질량중심계, 실험실계의 서로 다른 궤적과 반응 시점을 유지한다. 운동과 위치 그래프, 현재 시점까지의 CSV를 같은 계산 상태에서 만든다.
- 가속 전하의 방사 1개: 원본의 0.025 반복 덧셈 시계와 20개 파면을 유지한다. 시계의 부동소수점 누적값이 파면의 재시작에 영향을 주므로 단순 n×0.025로 치환하지 않는다. 전체 궤적을 매 프레임 다시 계산하지 않고 준비한 경로와 현재 표지를 사용한다.
- 양성자·중성자 스핀 1개: 24개 구획과 두 방향, 스핀/자기모멘트 화살표를 유지한다.
- 핵 구조·들뜬 핵 구조 2개: 135개/87개 핵자의 원래 격자, 원근 투영, 깊이 정렬, 회전과 흔들림 범위를 유지한다. 현대적인 파랑/회색 원형 SVG로 다시 그린다. 시점을 끌어 바꾼 다음 재생해도 그 방향에서 회전이 이어진다.

[6개 원본 함수 계산 대조](nuclear-next-source-report.json)는 485,520개 수치, [2개 핵 구조 계산 대조](nuclear-next-structure-source-report.json)는 110,514개 수치를 확인한다. 이는 비공개 원본 함수 실행과 독립 구현의 **소스 계산 대조**다. 실제 원본 실행 대조와 구분한다.

[실제 원본 스핀 대조](nuclear-next-runtime-report.json)는 원래 타이머의 27개 관측 상태와 방향 체크박스 클릭에서 216개 수치를 확인한다. [AS3 핵반응·방사 실제 실행 대조](nuclear-next-as3-runtime-report.json)는 원본 클래스와 타이머를 유지한 자연 재생에서 8,475개 입자 좌표·시간값을 확인한다. 원본의 모든 시간 단계나 방사 파면의 모든 점을 실제 실행에서 확인한 것은 아니며, 소스 계산 대조와 구분한다.

[6개 화면 검사](nuclear-next-ui-report.json)와 [2개 핵 구조 화면 검사](nuclear-next-structure-ui-report.json)는 320/768/1360 화면에서 재생·정지·끝에서 다시 재생·현재 상태 CSV·크기·끌기·방향키를 해당 모델에 맞게 확인한다. 움직이지 않는 도식에는 진행 막대를 추가하지 않는다.

## 명시적인 차이와 한계

원본의 핵 구조 색과 흔들림에 쓰이는 난수는 같은 상태를 다시 볼 수 있도록 고정했다. 소스 격자/투영 대조도 동일한 고정 난수로 실행하며, 원래 Flash의 모든 무작위 실행과 같은 궤적이라는 뜻이 아니다. 이 차이는 교재 화면에도 안내한다. 원본의 구형 그라데이션과 8개 곡선 조각을 새 원형 SVG로 정리했다.

원본의 물리 눈금·위상·반응 순서는 보존하되, 탐색·CSV·시간 그래프는 학습을 돕기 위해 추가했다. 반응의 초기/반복 경계와 좌표의 0.05 px 저장 오차는 각각의 보고서에 기록한다. 원래 타이머의 모든 실행 순서, 모든 포인터 경로와 전체 수치 동등성은 아직 완료로 주장하지 않는다.

담당 15개 중 8개 구현이며, 나머지 7개는 전체 작업 목록에서 이어간다: ITER, 원자력발전소, 무거운 하전입자와 물질의 상호작용, 감마붕괴, 핵력의 양자상태, 우즈–색슨 퍼텐셜, 우라늄 분열파편 분포.

실제 AS3 실행에서 실험실계 모형의 첫 질량중심 표지가 x=46.3이며, 원본 initPos가 x를 초기화하지 않아 자연 반복 뒤에는 x=195가 남는 것을 확인했다. 이 원본의 초기 배치와 반복 이력을 모델·표지·CSV에 반영했고, 소스 검사에서 빠져 있던 n=0 및 반복 경계도 추가했다. 명시적인 초기화 버튼은 원본을 새로 여는 첫 배치로 돌아간다.
