# 두 번째 50개 병렬 리마스터 기록

2026-10-10. 묶음 전체를 50개로 제한하고 광학 20개, 현대물리 15개, 일반물리 13개, 핵물리 2개로 나누었다. 개별 프로그램은 원본 프레임을 재생하는 방식이 아니라 새 HTML 조작과 SVG 도형으로 구성했다. 배치 시작은 399/518개이고 완료 후 449/518개, 잔여 69개다.

## 모형과 화면

- 광학: 색지움 렌즈·색수차·코마·구면수차, GRIN 및 미세렌즈, 분산과 프리즘의 광선 진행. 광원·렌즈·관측면의 역할을 구분하고 광선, CCD, 포락선·혼돈원 및 수차 표시를 계산과 연결한다.
- 현대물리: 섭동, 결정에서의 물질파, 장벽·계단·조화 퍼텐셜, 파동묶음과 중첩, 확률밀도·양자 이중슬릿·바퀴 확률, 일반 퍼텐셜과 방사형 정상상태 및 수치 적분. 입력, 파동함수, 확률밀도, 퍼텐셜과 CSV를 동일한 계산 상태에 연결한다.
- 일반물리: 기체 입자와 충돌, 회전 투사체, 연결 용수철·종파, 위상자, 도미노, 줄과 2차원 진동자, 파동 전파. 기본 빠른 진행과 느린 관찰, 힘 화살표, 실제 투사체 끝점 궤적 및 그래프를 제공한다.
- 핵물리: 일반 방사형 퍼텐셜의 정상상태와 별도의 퍼텐셜 그래프. 여섯 퍼텐셜·각운동량별 에너지 및 파동함수 계산과 세 퍼텐셜의 정적 도식을 구분한다. 원본 그래프 프로그램의 계산 함수는 에너지 적분을 호출하지 않으므로 에너지 결과를 임의로 추가하지 않는다.

파랑·회색과 테마 변수, 그래프 선 투명도 0.65를 사용한다. 시간 조작 막대는 하단에 두며 정적 입력 모형에는 재생·프레임 막대가 없다. 복잡한 그래프는 좁은 화면 안에서 가로로 이동하며 페이지 자체의 가로 넘침을 방지한다.

양자 적분은 worker에서 계산한다. 원본의 511/512/680점 적분과 CSV 수치는 유지하면서 시공간 그림에 전달하는 이력만 약 25행·8격자 간격으로 줄여 수만 개의 SVG 요소를 매 프레임 작성하는 부하를 줄였다. 핵물리 입력 계산은 입력을 모아 실행하고 이전 결과는 최신 상태를 덮어쓰지 않도록 한다.

## 서로 다른 검사 근거

[50개 항목별 증거](parallel-remaster-batch50-02-report.json)는 원본 SHA-256, 현재 구현 해시, 소스 계산, 원본 실행 및 새 화면 검사를 각각 연결한다. [전체 이식 대장](flash-migration-ledger.json)과 [225개 진행 기록](parallel-remaster-progress.json)은 구현이 없는 항목을 완료로 세지 않는다.

원본 실행 대조는 원래 문서 클래스·ABC·타이머 및 원본 태그를 유지한 SWF에 읽기 전용 관측자를 붙여 실제 Ruffle에서 관측했다. 원본 소스 함수를 별도로 실행한 계산 대조를 원본 실행 증거로 대신하지 않는다. 관측한 수치의 최대 오차도 저장하며 값이 없는 기록을 임의로 0으로 채우지 않는다.

이번 50개에는 소스 계산 3,516,895개 비교와 실제 원본 실행 144,290개 수치 비교를 기록했다. 광학의 수치 계산 부분은 변경 없는 프로그램·커널·어댑터의 기존 독립 증거를 재사용했으며, 렌더러의 즉시 초기화 수정은 새 화면 검사 60건·1,113개 검사로 검증했다. 수치 검사를 새로 실행한 것으로 표기하지 않는다.

실제 실행 대조에서 AS3의 `int` 인자 변환 때문에 조화 퍼텐셜의 코사인 진폭이 달라지는 문제를 확인하고 변환을 반영했다. 난수 결정 및 미세렌즈는 원본의 공개 초기 상태를 한 번 읽어 독립적으로 진행한 결과를 대조한다. 매 프레임 원본 값을 복사하여 일치시키는 방식이 아니다. 난수 생성의 모든 이력에 대한 동등성을 뜻하지 않는다.

세 화면 크기(320/768/1360px)의 개별 입력·선택·끌기·CSV 검사와 실제 읽기 페이지 검사를 수행한다. [전체 재생 검사](playback-ui-report.json)는 449개×3폭의 1,347건에서 카운터뿐 아니라 SVG 도형이 변하는지, 정지하면 멈추는지, 끝에서 재생하면 다시 움직이는지 확인한다. 최종 자산 수정이 있는 50개는 다시 검사하고 변경하지 않은 자산의 해시를 검증한 뒤 합쳤다. 파일 이름이 같은 두 파동묶음은 원본 전체 경로로 구분하며 기존 파동·중첩 모형도 세 폭에서 별도로 재검사했다. 전체 1,347건이 통과했다.
