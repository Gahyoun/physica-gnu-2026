# 전체 단원 읽기 화면 확장

2026-10-05. 원저자 정기수 교수님의 단원 순서와 기존의 디자인을 유지한다.

## 현재 범위

| 대단원 | 읽기 화면 |
|---|---:|
| 힘과 운동 | 29 |
| 파동 | 65 |
| 열과 물질의 상태 | 28 |
| 전기와 자기 | 43 |
| 빛 | 178 |
| 현대물리 | 164 |
| 핵물리 | 59 |

기존 양자통계 8쪽은 상세 복원본이다. 새 558쪽은 주제별로 독립 작성한 학습 핵심과 질문, 원본의 절 제목·수식을 함께 읽는 화면이다. 원본의 모든 설명·예제·질문·실험 지시문을 재서술한 완성 교재가 아니다. 같은 주제의 여러 쪽에서는 공통 학습 핵심이 반복되며 원본 절과 수식이 페이지마다 달라진다. 텍스트가 없는 원본 절에는 해당 원본 절로 가는 링크를 표시한다. 2026-10-05 사용자 요청에 따라 읽기 페이지·목록의 진행 상태 배지와 목차의 양자통계 바로가기를 제거했다. 대조 범위는 이 문서에 기록한다.

새 보충 탐구는 **79종의 독립 모델**을 556쪽에 배치한 것이다. 반복 배치를 서로 다른 복원 프로그램으로 세지 않는다. 기존 개별 복원 인터랙션은 17개다. 원본의 1,000개 이상 멀티미디어를 전부 이식했다는 뜻이 아니다. 보충 탐구는 실제 모형의 이름·단위·근사를 표시하고, 원본의 특정 Flash·Canvas·Java 프로그램과 구별한다.

원본의 상세한 본문 재서술, 원본 그림과 실험 지시문의 대응, 페이지별 원본 프로그램 분석·개별 이식·물리 검증이 후속 작업으로 남아 있다. 이 문서와 공개 페이지에서 이를 완료로 표시하지 않는다.

## 빌드 입력

- `src/catalog.json`: 단원 순서와 페이지 ID, 제목, 원본 링크.
- `src/book-survey.json`: 원본의 SHA-256, 짧은 절 제목, 수학식, 멀티미디어 URL. 원본 본문 문장이나 실행 코드를 포함하지 않는다.
- `src/topic-guides.mjs`: 147개 나머지 주제의 독립 서술·핵심 관계·탐구 질문. 기존 2개 양자통계 주제는 `src/content.mjs`에 있다.
- `src/book.mjs`: 원본 순서대로 기존 상세 복원과 새 읽기 화면을 합친다. 558개의 `lesson-ID.html`을 생성하며 기존 `lesson.html?id=ID` 주소는 해당 읽기 화면으로 이동한다.
- `assets/book-models.mjs`: DOM과 분리된 독립 물리 계산.
- `assets/book-labs.mjs`: SVG·슬라이더·범례·결과·재생/정지/초기화. 페이지에 있는 모형만 초기화하며 화면 밖과 숨김 탭에서는 재생을 멈춘다.

## 수식 처리와 대조

모든 수식은 빌드에서 KaTeX HTML/MathML로 컴파일하며 클라이언트에서 원본 MathJax나 Flash를 실행하지 않는다. 옛 `\array`·`\matrix`·`\eqalign`·`\cases`·`\scr` 표기를 호환 매크로로 변환한다. `split`은 `aligned`, `multline`은 `gathered`, 색 상자 `bbox`는 `boxed`로 바꾼다. 원본의 `label`과 `require`는 제거하고 반중성미자 아래첨자의 괄호를 명시한다. 열에너지 `kT`는 `k_BT`로 표시한다.

원본 수식의 렌더링 성공은 모든 식의 물리적 정확성을 감수했다는 뜻이 아니다. 확인한 정리 사항:

- 운동량 첫 쪽: 로켓 자체에 닫힌 계의 `F=d(mv)/dt`를 직접 적용하는 원본 전개를 제외하고, 열린 계의 운동량 유출입을 별도로 고려해야 한다고 학습 핵심에 설명했다.
- 전자기파 복사 4쪽: 전도 매질의 복소 파수 제곱 관계에서 `εμω`를 차원에 맞게 `εμω²`로 정리했다.
- 핵무기 2쪽은 질량–에너지의 일반 원리와 역사·사회적 영향의 학습 안내로 한정한다.

본문의 녹색 강조는 해당 쪽의 실제 관련내용 목록에 포함된 단어에만 적용하고 수식 내부를 변경하지 않는다. 표제어·자료 목록·검색·네트워크는 같은 정적 읽기 주소로 연결한다. 원본의 절 이름에 해당하는 로컬 앵커가 있으면 그 위치로 이동한다.

`node --test tools/*.test.mjs`:

- 79개 보충 모형의 초기값·각 슬라이더 최소/최대·동시 경계 설정에서 계산값 유한성.
- 충돌의 운동량·반발계수·탄성 에너지 보존.
- 감쇠 모형의 초기조건·임계감쇠 연속성.
- 정입사 프레넬 값·브루스터각·전반사·에어리 첫 영점.
- 양자 조화진동자와 중첩 상태의 확률 정규화.
- 붕괴 계열의 같은 붕괴상수 극한·라플라스 반복의 수렴.
- 기존 통계·복사·비열·자유전자·중성자별·방향 네트워크 검사.

`tools/book-browser-check.mjs`: 전체 566쪽의 수식 오류·중복 ID·내부 링크·화면 넘침·런타임/자산 오류를 확인한다. 각 보충 모델을 한 쪽씩 선택해 79개 모델, 306개 슬라이더 경계 조작, 320/768/1360px 화면과 재생/정지를 확인한다. 결과는 `book-browser-report.json`에 저장한다.

기존 `tools/browser-check.mjs`로 양자통계 인터랙션·논문 목록·전체 목차·검색·테마·개념 네트워크의 회귀 검증도 실행한다.

일반적인 양자 확률과 불확정성 관계의 보충 참고: [OpenStax University Physics 3, 7.2](https://openstax.org/books/university-physics-volume-3/pages/7-2-the-heisenberg-uncertainty-principle). 원본의 절과 수식 출처는 각 페이지의 원본 링크와 조사 JSON의 SHA-256에 기록한다.

## 링크만 있던 절의 본문 복원

`src/section-content.mjs`와 `src/section-library.mjs`는 원본 페이지·절별로 대조한 독립 서술을 기록한다. 이전에 원본으로 넘어가는 링크만 있던 368개 절을 모두 개념별 설명으로 대체했다. 기존 상세 파동 절을 포함해 284쪽의 387개 절에 직접 읽을 수 있는 새 설명을 제공한다. 주요 관계식 26개를 추가하고 파동의 수학적 표현 1쪽에는 공간/시간 표현, 줄의 파동방정식 유도, 일반해와 초기조건, 독립 제작한 장력 도식을 넣었다. 진동자 5종은 ‘진동자’와 ‘연결된 진동자’ 설명 바로 아래에 HTML로 배치했다.

제목과 수식만 있던 다른 절이나 원본의 모든 예제·그림·실험 지시문까지 상세 복원한 것으로 간주하지 않는다. 새 서술은 개념과 모의실험 해석을 담으며 원문 문장을 복제하지 않는다. 개별 애니메이션 전체의 HTML 이식과 조작·수치 대조는 진행 중이다.

누락된 설명을 외부 링크로 대신하는 빌드 분기를 제거했다. 설명도 수식도 없는 절은 빌드 오류가 되며, 전체 566쪽에서 외부 ‘절 읽기’ 블록이 없는지 단위/브라우저 검사한다. 새 문자의 로컬 폰트 포함 여부, LaTeX 컴파일, 원본 앵커와 내부 링크도 확인한다.
