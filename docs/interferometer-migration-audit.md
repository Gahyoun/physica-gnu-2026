# 마이컬슨 간섭계·고반사 박막 이식

원작: 경상국립대학교 물리학과 정기수 명예교수님. 원본 SWF는 원본 애니메이션 목록에 보존한다. 웹교재는 독립 HTML 조작과 새 SVG 도형을 사용하며 원본 프레임 이미지·글꼴·로고를 불러오지 않는다.

- `michelsonsim.swf` → 5-4-1-2: 거울 수평 이동·기울기, 구면파/평면파, 가상광원의 파면, 분기한 두 광선의 이동. 실제 광원과 가상광원을 구별한다. 광선 좌표와 시간 그래프·CSV는 같은 계산 단계에서 읽는다.
- `highref.swf` → 5-4-5-3: n=2/1.25, 두께 30/48인 교대층과 일곱 경계의 반사파. 원본의 21개 파장 입력과 100 ms의 위상 증가를 유지한다. 입사 방향과 위로 되돌아오는 각 반사파를 표시한다. 일곱 진폭의 합과 선택한 반사파의 시간 그래프·CSV를 추가했다.

파랑·회색과 곡선 불투명도 0.65를 사용한다. 진행 막대는 장면 아래에 고정된 행에 놓는다. 화면 밖과 숨긴 탭에서 재생을 중단하고, 입력 변경 시 처음부터 계산한다.

## 보존한 원본 특성과 표시 차이

마이컬슨의 원본 root는 10 fps의 2프레임 루프에서 콜백을 실행하므로 5 계산 단계/초이다. 60번째 호출에서 원본 time이 0으로 돌아오며 두 번째 광선의 마지막 좌표가 남는 동작도 보존한다. 파면 간격 3은 원본 도식의 눈금이며 물리적인 파장 입력이 아니다. 두 슬라이더의 실제 드래그 끝값은 원본 트랙 여백에 따라 명목상 한계와 다를 수 있다. HTML은 명목상 끝값을 직접 선택할 수 있다.

고반사 박막은 원본부터 감쇠를 생략한 위상 교육 모형이다. 일곱 반사 진폭의 합을 실제 반사율로 해석하지 않는다. 원본이 가로선으로 그린 2눈금 간격의 진폭 끝점을 SVG의 매끄러운 연결선으로 표현한다. 경계에서 굴절률을 먼저 적용한 원본의 이산 위상 계산과 근사 상수를 그대로 사용한다. 원본의 끝없는 위상 시각을 HTML에서 126단계의 재생 구간으로 나누고 반복·되감기를 추가했다.

두 모형은 HTML에서 재생 전 상태로 시작하며 진행 막대·속도·반복·현재 CSV는 추가 조작이다. 입력 변경 즉시 광선도 초기화하고 정지한다. 원본의 모든 이벤트 순서와 Adobe Player의 전체 동등성을 주장하지 않는다.
