# 리마스터 재생 점검 · 2026-10-07

현재 HTML 대응본 **239개 전체**를 Chromium의 **320·768·1360 CSS px** 화면에서 검사했다. 총 **717건 모두 통과**했다. 이 가운데 실제 재생 모형은 **138개**, 재생 버튼이 없는 정적·입력형 도식은 **101개**다. 평형 또는 경계 위치가 기본값인 7개 모형은 기본 상태를 기록한 뒤, 변위를 주거나 안쪽 위치로 바꿔 실제 운동을 별도로 확인했다.

## 수정한 문제

- **SVG 준비 지연:** 아직 준비되지 않은 도식에서 재생 클릭이 아무 작업도 하지 않았다. 직접 재생을 누르면 SVG를 준비하고 시작하도록 바꿨다. 준비 전후의 그림 높이를 확보해 아래 도식과 버튼이 밀리는 현상도 줄였다.
- **화면 가시성 판정:** 스크롤 이전의 관찰 결과나 같은 관찰 묶음에서 생긴 레이아웃 변화가 재생을 중단할 수 있었다. 다음 화면 프레임에서 현재 위치를 확인한 뒤 화면 밖의 모형을 정지한다.
- **끝에서 재생:** 타임라인·파동·연결 진동자의 재시작 화면을 즉시 갱신한다. 마지막 프레임에서 재생하면 처음부터 시작하며, 느린 모형에서도 이전 끝 화면이 남아 있지 않는다.
- **강제진동 시간 슬라이더:** `1/15`의 소수 문자열을 HTML `step`으로 쓰면 브라우저가 20초를 19.933…초로 제한했다. 입력 처리는 원래 계산 간격에 맞춰 유지하면서, 정확한 20초 선택과 재시작을 지원한다.
- **전이 도식:** 자발방출·유도방출·흡수의 궤도 전자와 에너지준위 표지는 같은 원본 프레임의 전이 비율과 정확한 시작·끝 위치를 사용한다. 상태 문구와 전이 화살표도 같은 단계에 맞춘다.
- **조작 영역:** 재생/일시정지 글자 수가 바뀌어도 버튼 폭이 유지된다. 대기 구간·평형·경계 정지·재생 완료를 안내하고, 진행 막대 아래에 상태를 배치해 막대가 움직이지 않도록 했다.

## 확인 범위

[전체 HTML 재생 기록](playback-ui-report.json)은 실제 교재 링크에서 재생 버튼을 클릭하고, SVG 장면의 좌표·경로·변환이 시간에 따라 달라지는지 확인한다. 시간 숫자만 바뀌어서는 통과하지 않는다. 일시정지 후 도형 정지, 이어 재생, 마지막 위치로 이동 후 재시작을 검사했다. 원본의 대기 구간은 중간 단계에서도 재생해 확인했다.

[신고 사례 회귀 기록](playback-regressions-ui-report.json)은 ‘몇 가지 진동’의 477단계·4배속·반복 끔 조건, 일차원 충돌, 진행 막대 위치, 강제진동 20초 끝값, 준비 관찰 이벤트 없이 직접 재생하는 상황을 확인한다. 세 전이 도식의 60프레임을 세 화면 크기에서 검사한 **540개 HTML 자세**에서도 두 표지의 전이 비율이 일치했다.

역학 15종의 입력·수치·CSV·화면 밖 정지 검사와 SVG 도식 29종의 조작 검사도 재실행했다. 파동 재생 코드가 바뀌어 원본 9종의 실제 Ruffle 수치 대조를 다시 실행했고, 기록한 비교 범위를 통과했다. 물리 계산식과 보존된 원본 SWF는 수정하지 않았다.

**한계:** 화면 크기 검사는 실제 태블릿 장치나 모든 브라우저 엔진의 인증이 아니다. 기본 입력과 명시한 회귀 조건의 재생 QA이며, 모든 연속 입력·모든 원본 이벤트 순서의 동등성을 뜻하지 않는다. 전체 원본 518개 중 **279개는 개별 HTML 이식 대기**다. 원본 런타임 대조는 [별도 기록](original-runtime-audit.md)으로 유지한다.

## 재실행

로컬 사이트와 설치된 Playwright 경로를 준비하고 실행한다.

```sh
node tools/playback-browser-audit.mjs
node tools/playback-regressions-browser-check.mjs
node tools/playback-clock-check.mjs
node tools/fundamental-browser-check.mjs
node tools/timeline-ui-check.mjs
node --test tools/*.test.mjs
```

주소는 `PHYSICA_BASE_URL`, 설치 경로는 `PHYSICA_PLAYWRIGHT`로 지정한다. 전체 기록에는 검사 대상 브라우저 모듈의 SHA-256을 포함하며, 이후 코드가 달라지면 증거 검사가 실패하도록 했다.

새로 추가한 도식·10개 질점 16개의 상세 조작 검사 32건과 실제 Ruffle 입력 대조는 [별도 이식 기록](scene-migration-audit.md)으로 제공한다. 정적 도식 11개는 카메라 조작으로, 스핀·각운동량 2개와 질점 파동 3개는 실제 시간 운동으로 검사했다.

양자파동·확률분포 17개를 포함해 전체 재생 검사를 다시 실행했다. 신규 동적 모형 10개는 같은 시간의 파동·벡터·확률 또는 고전 입자 운동을 확인했고, 정적·입력형 모형 7개는 별도 입력 검사로 확인했다. [양자 모형 조작 검사](quantum-ui-report.json) 34건과 [실제 원본 대조](quantum-runtime-report.json)를 함께 제공한다.

광선·스펙트럼·굴절·상대성이론 25개를 포함한 전체 재생 검사를 다시 실행했다. 25개 새 모형의 75건 입력 검사에는 다크 모드와 하단 진행바도 포함한다. 쿨롱 모형은 RAF 첫 프레임의 시각이 재생 클릭보다 앞설 때 음수 단계를 만들 수 있어 시간차를 0 이상으로 제한했다. [1–500 ms 시각 역전 재현](playback-clock-report.json)과 기존 신고 사례를 다시 검사했다.
