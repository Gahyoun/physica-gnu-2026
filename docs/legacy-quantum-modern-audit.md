# 현대물리·양자 Java 애플릿 HTML 이식 감사

2026-10-10. 새 실행 클래스 19개를 실제 HTML/SVG/Canvas 모형으로 이식했다. `reldistortion.zView`의 두 원본 래퍼는 하나의 실행 클래스와 두 관측 방향 선택으로 묶었다. 기존 3차원 상자·조화진동자·수소 파동묶음·Kepler 파동묶음 4개와 합쳐 양자 manifest는 23개이다. 원본 바이너리와 역분석 파일은 공개 사이트 실행 자산에 포함하지 않았다.

## 검증의 의미와 범위

`legacy-quantum-modern-reference.json`, `legacy-quantum-packet-reference.json`, `legacy-quantum-potential-reference.json`은 **원본 Java 클래스의 계산 결과**다. `tools/legacy-quantum-runtime-reference/`의 3개 Java 프로그램이 이를 얻고, `tools/legacy-quantum-modern.test.mjs`가 별도로 작성한 JS 계산과 대조한다. 원본 초기 파동, FFT 부호·정규화, 경계 영상, ADI 순서, 퍼텐셜, 시간 간격을 실제 배열 값으로 비교했다. 수치 비교 허용치는 일반 계산 3e-11, FFT·격자 시간진화 3e-9의 상대/절대 혼합 허용치이다.

실제 원본 GUI 실행·옵션 조합 결과는 공통 `legacy-original-gui-report.json`에 별도로 기록한다. GUI 실행 가능 모델의 선택지/체크박스 유한 조합, 슬라이더 최솟값·중간값·기본값·최댓값 및 버튼을 실행했다. 텍스트 입력의 모든 문자열, 모든 마우스 경로, 연속 실숫값의 무한 조합을 조사했다는 뜻은 아니다. 원본에 실제 존재하는 서로 다른 파라미터 범위와 기본값은 manifest에 기록했다.

`legacy-quantum-modern-ui-report.json`은 새 19개 모델을 실제 Chromium에서 실행한 결과다. 16개 시간진화 모델의 재생·일시정지, 71개 활성 선택 입력, 152개 범위 입력 양 끝, 44개 체크박스 입력을 확인했다. Java 수치 fixture는 888개 실행 사례이며 5,538개 배열 위치와 개별 함수 값으로 대조한다. 별도 `legacy-quantum-modern-pointer-report.json`은 6개 모델의 대표 마우스 회전·전자 추가와 시각 옵션의 시간 보존을 검증한다. 3개 정적 모델은 재생 버튼과 의미 없는 프레임바를 제공하지 않는다. 0 K 흑체의 최대 복사 파장은 정의되지 않으며 해당 상태를 화면에 명시한다. 동일한 한 입자 상태의 반대칭 결합은 영벡터여서 허용 상태가 아니므로 이를 별도 설명한다.

## 원본 제약과 표시 차이

- `HydrogenApp`과 `HydrogenMixApp`는 native VTK 렌더러를 요구한다. 원본 GUI 전체는 실행하지 못했지만 순수 Java 수소 함수와 각 상태의 수치는 직접 실행해 대조했다. 원본 61³ 물리 격자는 계산·정규화에 보존한다. 새 SVG 등고면은 그 격자의 매 두 번째 점(31³)에서 marching tetrahedra로 생성하므로 VTK 픽셀·메시와 같다는 주장은 하지 않는다. 원본 16-bit 정수 양자화 대신 부동소수 진폭을 사용한다. 위상 색은 경상국립대 파랑·회색으로 정리했다.
- Stern–Gerlach의 `sterngerlach.3ds` 및 `glass.material`, `chrome.material`, `blue.material`이 원 서버에서 HTTP 404다. 새로운 SVG 장치는 소스 좌표 계산을 읽기 쉽게 보여 주기 위한 재구성이고 원본 3DS 메시의 완전 복구가 아니다. 검출 그래프는 실제 이번 재생에서 집계한 검출 수이며 임의의 Gaussian 곡선을 붙이지 않는다. 원본 모든 3D 카메라 키 조합은 아직 비교할 수 없다.
- 두 번째 상대론 래퍼는 `viewdirection`을 제공하지만 클래스는 `viewDirection`을 읽어 원본에서 방향 값이 적용되지 않는다. 새판에는 의도한 두 번째 방향을 선택할 수 있도록 제공하고 본문 안내에 차이를 표시했다. 무작위 물체 배치는 비교 가능한 고정 배치로 표시하며 원본과 픽셀 단위 배치가 같다는 주장은 하지 않는다.
- 원본 2차원 상자의 고전 파동 체크박스는 비활성 상태여서 새판에 작동하는 기능인 것처럼 추가하지 않았다.
- 2차원 ADI와 두 입자 원본 커널은 원본 계산 순서와 주기적 재대칭화를 보존한다. 재대칭화 사이 부동소수/분할 연산의 작은 교환 오차는 임의로 매 프레임 보정하지 않는다.
- 정적 구름·흑체는 시간 재생이 필요하지 않는다. 확률밀도만 보이는 수소 고유 상태 역시 밀도는 정상상태라서 고정되고, 진폭 모드에서는 원본 에너지 위상에 따라 색상이 변한다. 사용자가 일시정지하면 장면·그래프의 시간이 함께 멈춘다. 시각 옵션·카메라 변경은 시간을 초기화하지 않는다.

## 최적화와 디자인

파랑과 회색 계열, 모든 그래프 선 alpha=0.65. 원본 이미지의 프레임 재생이 아니라 새 도형·텍스트와 계산 상태를 그린다. 양자 상태를 계산하는 격자는 축소하지 않았다. 자유 2D 파동은 정확히 분리되는 초기 조건을 이용하여 512×256 FFT를 두 1D FFT로 최적화했으며 원본 전체 FFT와 직접 대조했다. 수소 고유 함수 격자는 캐시하여 재생 중에는 에너지 위상만 갱신한다. 화면 밖과 숨겨진 탭에서는 RAF를 멈추고, 돌아올 때 밀린 시간을 폭주시키지 않는다. 기본은 빠른 원본 간격이며 느리게 선택을 제공한다.
