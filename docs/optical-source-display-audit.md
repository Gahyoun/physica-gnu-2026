2026-10-08. 광원이나 광선의 시작이 작은 점·희미한 경로로만 보이던 22개 광학 모형에 출발 위치와 진행 방향을 표시했다. 원저자는 정기수 경상국립대학교 명예교수님이며, 표식과 설명은 리마스터에서 추가한 학습 보조 표현이다.

## 계산·표현 원칙

출발점은 기존 원본 대조를 마친 광선 상태와 작도 좌표에서 직접 구한다. 물체 끝이나 입사 광선의 시작을 실제 전구라고 표현하지 않는다. 공진기의 초기 광선 위치와 빔의 진행 방향 역시 새로운 외부 광원을 뜻하지 않는다. 파면·위상자, 코르뉴 적분, 개구의 수학적 분포에는 임의의 광원 그림을 만들지 않았다. 이미 입사/반사/굴절파와 k 방향을 표시하는 3차원 반사·굴절 모형과 광원이 표시된 박막 모형도 유지한다.

고정된 출발 표식과 이동하는 광선 점을 구분한다. 재생·탐색·반복 중 출발 위치는 첫 상태에 남으며, 광원 조건·입사각·슬릿 간격을 바꾸면 함께 갱신된다. 원래 광선 전파·수치·재생 시간·그래프 계산을 변경하지 않았다. 안정한 모드가 없는 공진기에는 진행 방향도 숨긴다.

표식은 GNU 파랑과 배경색의 벡터 도형이다. 방향선의 불투명도는 0.65이며 라이트/다크 테마를 따른다. 표식과 글자에는 포인터 입력을 받지 않도록 설정해 광원 위치 클릭과 렌즈/빔 손잡이 드래그를 가리지 않는다. 상단 설명을 위한 여백을 두고, 시작점이 장면 가장자리에 있는 경우에도 표식이 잘리지 않도록 경계를 확장했다. 새로운 재생 타이머를 추가하지 않았다.

## 검증 기록

광원 표시 전용 검사 66건, 입력·탐색·테마 변경을 포함한 477개 화면 상태가 통과했다.

- [렌즈·거울 작도](light-ui-report.json), [광학기구 조합](matrix-ui-report.json), [광선 배열](ray-ui-report.json), [가우스 빔](beam-ui-report.json), [회절](diffraction-ui-report.json), [간섭·프레넬](optics-ui-report.json)의 기존 재생·입력·SVG·수치/CSV 검사를 다시 실행한다.
- 수치 함수와 화면 코드가 같은 파일인 `native-optics.mjs`는 [원본 Ruffle 실행 검사](optics-runtime-report.json)를 다시 수행한다. 나머지 별도 물리 계산 파일과 보존된 SWF는 변경하지 않는다.
- [전체 재생 검사](playback-ui-report.json)는 최종 브라우저 모듈에서 다시 수행한다.

이 기록은 광원 표시와 기존 동작의 회귀 검증이다. 전체 Flash의 모든 입력 조합이나 원본 픽셀과의 완전 일치를 새로 검증했다는 의미는 아니다.
