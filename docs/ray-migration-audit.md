## 표현·입력 차이와 남은 범위

처음에는 정지 상태다. 원본 배열·두 거울은 80/90/100콜백 뒤 무작위 광선으로 자동 재시작하지만, 새 화면에서는 현재 조건의 재생 구간을 탐색하고 선택한 반복을 재생한다. 원본 난수 범위는 ‘새 광선’ 버튼으로 제공한다. 원본 거울의 좁은 클릭 영역은 새 SVG에서 시작 영역으로 확장했다. 두 거울에 추가한 초점거리 슬라이더는 원본 클릭 난수 범위를 직접 선택하는 편의 기능이다.

입력 변경은 새 실험으로 다시 시작한다. 원본 두 배열은 초점거리 변경 때 진행 중 광선을 유지한다. 원본 공진기는 슬라이더 변경 후 시간과 이전 반사 표를 남기지만, 새 화면은 이전 실험과 섞이지 않도록 지운다. 원본 갱신이 멈춘 생존 비율 문구는 현재 단계의 생존 수로 표시한다. 원본 표시 색·글자·장식·겹침을 복제하지 않는다. 공진기 장면의 누적 광선은 최근 두 반사 구간만 그려 긴 경로의 DOM 갱신 부담을 줄인다. 추가 시간 그래프·CSV·관측 광선 선택은 원본 클립보드/반사 그래프와 구별되는 학습 기능이다.

렌즈 배열의 모든 초점거리 쌍 검사는 지정한 첫 평행광선 구간에 한정한다. 모든 시작 좌표 × 초점거리 × 난수 이력, 공진기의 모든 슬라이더 곱과 무한 시간·동시 조작·이벤트 순서, 원본 표시 픽셀 및 Adobe Player 자체와의 동등성은 남아 있다. `fullEquivalence=false`를 유지하며 함수 비교와 HTML 화면 QA를 실제 원본 런타임 전수 검사로 합산하지 않는다.

재실행은 로컬 서버와 Playwright 경로를 준비한 뒤 `node tools/ray-source-check.mjs`, `node tools/ray-runtime-check.mjs`, `node tools/ray-browser-check.mjs` 순으로 수행한다. 원본 함수 검사는 별도 비공개 ActionScript 조사 경로를 요구한다. 실제 런타임·HTML 검사는 `PHYSICA_BASE_URL`과 `PHYSICA_PLAYWRIGHT`를 사용한다.
