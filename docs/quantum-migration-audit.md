## 명시한 차이

1. 원본 `boxprobality`의 그려진 곡선은 **sin⁴**이지만 구간 확률 적분은 정규화한 **sin²**다. 이 차이를 덮어쓰지 않고 원본 곡선과 정규화 밀도를 구분해 표시한다. 구간 확률은 원본 적분을 따른다.
2. 장벽 E=V에서 원본은 q=10⁻¹⁰과 큰 계수의 상쇄를 이용한다. HTML은 연속적인 선형 극한해를 사용한다. 해당 경계의 원본 R/T 퍼센트 질의에만 절대 허용 오차 10⁻⁶을 적용한다. 비공개 함수 검사에서도 그 경계의 파동값 자체는 동등성 근거로 사용하지 않는다. 폭 0은 계단이 아니라 장벽이 없는 극한이다.
3. 원본 조화진동자 파동함수는 π⁻¹/⁴ 정규화 계수를 생략한다. 원본 함수 눈금을 유지하며, 고전 입자와 양자 파동의 서로 다른 원본 시간 배율을 반영한다.
4. 원본의 무작위 초기 상태를 HTML에서는 재현 가능한 기본값과 명시적인 입력으로 제공한다. 무작위 시드·모든 재로딩 이력의 일치를 주장하지 않는다.
5. 복소 파동의 기울어진 공간 투영과 시간함수의 HSV 위상 색을 새 Cartesian 벡터·파랑/회색 곡선으로 재설계했다. 원본 픽셀·색상 일치를 검증한 것은 아니다.
6. 다른 디렉터리의 동명 `wavepacket.swf`는 별개 파일이다. 이번에는 `wave/superpose/wavepacket`만 이식했다. 나머지 파일을 자동으로 완료 처리하지 않도록 전체 경로와 ID를 검사한다.
