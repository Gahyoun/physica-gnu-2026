# 원형·직사각형 회절과 동공함수 · 2026-10-08

원형구멍 회절무늬(cir_difffr), 직사각형구멍 프레넬 회절무늬(rectdiff), 제르니케 다항식(zernike), 파면수차에 따른 동공함수(phaseAber)를 독립 HTML/SVG로 추가했다. 원본 SWF와 Ruffle 비교 페이지는 수정하지 않았다. 원본 프레임·비트맵·내보낸 그림은 리마스터 화면에 사용하지 않는다.

GNU 파랑과 회색으로 무늬·다항식·파면을 다시 그렸다. 그래프 선의 불투명도는 0.65다. 슬라이더를 바꾸면 장면과 단면이 같은 상태에서 갱신된다. 네 모형 모두 시간 재생을 하지 않는 입력형 모형이므로 재생 버튼과 프레임바가 없다. 동공함수의 시점 끌기와 단면 각도는 보기 조작이며 물리 계수를 바꾸지 않는다.

## 원본 수치의 보존

- 원형 회절: 원본의 30항 J₁ 급수, 중심의 |x| < 0.01 분기, 51개 반경 표본과 파장 380–680 nm, 밝기 1–50을 유지한다. 무늬의 포화 표시와 포화 전 강도 그래프를 구분한다. 원본의 파장별 RGB 표현은 GNU 파랑 계열로 변경했다. 원본 클립 크기에 대한 픽셀 동등성을 주장하지 않는다.
- 직사각형 회절: 적분표의 0.001 Simpson 간격과 잔여 구간의 0.01 합산 간격을 구별한다. 구멍 가로·세로 0.4–10, 100×100 사분면 표본과 네 대칭 사각형 위치, 노출 후 정수 반올림·255 포화·4 이하 생략을 유지한다. SVG path를 밝기별로 모아 수만 개 DOM 요소를 만들지 않는다. 가로·세로 중심 단면은 같은 분리형 강도식을 사용한다. 노출은 강도 수치를 변경하지 않는다.
- 제르니케: m=0–8, n=m,m+2,…,m+14, 201개 선택 곡선 표본과 101개씩의 비교 곡선을 유지한다. m 변경 시 n의 한계와 선택도 갱신한다. 정규화 계수를 임의로 추가하지 않는다.
- 동공함수: cos 10항·sin 7항, 계수 −1.5–1.5와 0.1 간격, 초기 a13S=1, 11×24 원본 격자와 높이 z=25W를 유지한다. 원본 초기 카메라 행렬과 투영을 사용하되, 새 SVG 격자 패치는 직선으로 구성했다. 원본의 곡선 패치·깊이 클립 구현과 픽셀 동등성은 별도 미대조다.

직사각형 원본은 시작 시 구멍 크기를 난수로 선택한다. 새 화면은 가로·세로 4로 시작하며 ‘다른 구멍’에서 동일한 난수 범위(2.4–5.4, 0.2 간격)를 제공한다. 원본 초기 노출 슬라이더는 2지만 실제 계산값은 40이다. 새 화면도 이를 보존하고, 슬라이더를 조작한 뒤에만 10×2^(단계−1)을 적용한다. 원본의 `drawTBtn` 참조는 실제 인스턴스가 아니며, 실제 버튼은 `copyTBtn`이다. 새 구멍 윤곽 체크박스는 추가한 보기 기능이다. CSV는 원본의 클립보드 내보내기를 대체한 다운로드 기능이며 201×201 포화 전 강도를 저장한다.

## 검증 근거

- [비공개 원본 함수 비교](aperture-source-report.json): **1,583,241회**. 원형의 모든 50×31 입력 조합과 51개 고리 강도, 제르니케의 모든 72개 유효 차수 조합과 201개 반경 표본을 검사했다. 직사각형은 모든 97개 단일 구멍 크기의 축 표본, 3,001개 C/S 위치와 8×3×3 선택 입력의 전체 사분면 강도·밝기를 검사했다. 동공함수는 17개 계수별 최소/0/최대와 네 개 동시 계수 설정의 전체 264개 값을 비교했다. 추출 ActionScript는 배포하지 않는다.
- [실제 원본 Ruffle](aperture-runtime-report.json): **48,281회**. 원본 슬라이더·버튼을 실제 포인터로 조작했다. 기본값과 각 끝값·기본값, 제르니케의 72개 차수 조합을 선택해 원본 상태를 읽었다. 동공함수의 264개 격자값·17개 계수·초기 카메라 행렬·모두 지우기 동작을 확인했다. 원형과 직사각형, 제르니케의 수치 함수 질의는 원본 함수를 호출한 관측이며 원본 계산을 JS로 대체한 것이 아니다. 직사각형 질의는 0.4/4/10 크기의 100개 축 표본이며 그 화면의 모든 실제 렌더 픽셀 관측이 아니다. 진단용 함수 호출이 임시 변수를 갱신할 수 있으므로 원본 입력/이벤트/수식 수정과 구분한다. 허용치는 수치 1e-7이다.
- [HTML 화면 검사](aperture-ui-report.json): **12건 = 4종 × 320/768/1360 px**. 모든 슬라이더의 최소/기본/최대, 종속 차수 범위, 구멍 윤곽·난수 버튼, 파면의 실제 시점 드래그·복원·각도·계수 초기화, 전체 CSV 행의 현재 입력 계산값 일치, SVG 전용과 alpha 0.65·라이트/다크·프레임바 없음 등을 확인했다.
- 전체 HTML 대응본의 재생 회귀는 [별도 기록](playback-ui-report.json)에 남긴다.

정적 파면의 시점 회전·추가 단면·CSV는 학습 편의 기능이다. 원본 전체 표시 픽셀, 연속 함수의 모든 실수 위치, 모든 97×97 구멍 크기와 노출의 곱, 동공함수의 31^17 동시 계수 조합, 모든 이벤트 순서와 카메라 이력은 미완료다. 모든 기록에서 `fullEquivalence=false`를 유지한다. 원본 함수 비교를 실제 런타임 누적 수치로 합산하지 않는다.

재실행: 로컬 서버와 Playwright 경로를 준비한 뒤 `node tools/aperture-source-check.mjs`, `node tools/aperture-runtime-check.mjs`, `node tools/aperture-browser-check.mjs`. 함수 비교는 비공개 원본 스크립트 경로를 요구한다. 웹 화면·런타임은 `PHYSICA_BASE_URL`과 `PHYSICA_PLAYWRIGHT`를 사용한다.
