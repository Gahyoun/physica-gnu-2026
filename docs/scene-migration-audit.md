# 개별 SVG·HTML 이식과 원본 실행 대조 · 2026-10-07

남은 337개 중 **16개**에 새 HTML 대응본을 추가했다. 누적 **197/518개**, 개별 이식 대기 **321개**다. 원본 그림이나 프레임 이미지 재생이 아니라, 수치 좌표와 방정식을 바탕으로 새 SVG·HTML 조작 화면을 구성했다. 원본 SWF는 수정하지 않았고 원본 목록에서 별도로 재생한다.

## 서로 구분하는 대조 근거

- [비공개 원본 함수와 수치 기하 비교](scene-source-report.json): 13개 도식, 2,600개 상태, **518,352회**. 스핀의 허용 10조합·각운동량의 허용 15조합 각각에 대해 100단계 전체를 검사했다. 구면좌표는 반지름 3개 × 극각 6개 × 방위각 5개, **90조합**이다. 정적인 도식은 모든 점·선분·곡선 제어점·면 좌표를 비교했다. 이 근거는 실제 Ruffle 실행 대조와 합산하지 않는다.
- [실제 원본 실행과 비교](scene-runtime-report.json): 16개, **74,355회**. 실제 원본의 양자수 버튼으로 허용 25조합을 선택하고, 관찰된 원본 단계에서 좌표를 비교했다. 구면좌표는 세 슬라이더를 실제로 끌어 경계·대표 **8조합**을 비교했다. 카메라 회전 후 점의 화면 좌표까지 대조하며 Flash의 0.05 px 좌표 양자화 허용치를 구분한다. 10개 질점 원본은 첫 질점을 양 방향으로 끈 뒤 모든 질점의 연속 계산 단계 위치·속도를 비교했다.
- [HTML 조작 검사](scene-ui-report.json): 320·1360 px에서 **32건**. 시점 끌기·키보드·초기화·면 표시·좌표 CSV·기본 화면 범위, 허용 양자수 25조합의 네 단계, 구면좌표 90조합을 확인했다. 세 질점 모형 각각의 **10개 질점 모두**를 독립 조작했다. 평면 운동은 각 질점의 수평·수직 입력을 따로 확인했다.
- [전체 HTML 재생 검사](playback-ui-report.json): 197개 대응본을 320·768·1360 px에서 검사한다. 시간 숫자뿐 아니라 SVG 장면이 실제로 변하는지, 일시정지·이어 재생·끝에서 재시작이 작동하는지 확인한다. 평형 기본값에는 별도 변위를 준다.

보고서에 모델 파일의 SHA-256을 남긴다. 코드가 바뀌면 테스트가 오래된 근거를 거부한다. 원본 함수는 비공개 진단 폴더에서 실행하며 웹에는 원본 코드·글리프·프레임 이미지를 포함하지 않는다.

## 보존과 변경 범위

원본의 세로 좌표 투영 부호를 화면까지 대조하여 바로잡았다. 질점은 원본의 질량 20·감쇠 0.995·동시 힘 계산·프레임 조건을 사용한다. 초기 변위가 모두 0이면 움직이지 않는 평형이며, 변위를 준 뒤 실제 운동을 확인한다.

HTML 시점 조작은 포인터 이동량에 따른 증분 회전과 정면·옆면·기본 시점을 제공한다. 원본의 누른 위치에 대한 지속 회전과 동일한 이벤트 시퀀스로 주장하지 않는다. 원본 좌표를 같은 카메라 행렬로 투영한 값은 별도로 대조한다.

원본에서 양자수를 바꾼 직후 자기 양자수가 새 범위를 벗어난 채 잠시 남을 수 있다. HTML은 즉시 허용되는 자기 양자수로 맞춘다. 그 과도 상태를 허용 25조합 전수 대조에 포함하지 않는다. 각운동량 0은 영벡터로 표시하며, 세차 도식은 전자의 고전적 궤도라는 뜻이 아니다.

구면좌표의 반지름은 원본처럼 하한 25를 기준으로 2씩 반올림하고 상한 180에서 제한한다. 극각 0–180°·방위각 0–450° 범위를 유지한다. 원본 극각 곡선 제어점의 z 좌표에 쓰인 별도 분모도 수치 대조에서 보존했다.

질점 끌기는 HTML에서 초기 조건을 설정하고 궤적을 다시 계산한다. 원본에서 재생 도중 여러 질점을 동시에 잡거나 임의 순서로 끌었을 때의 모든 이벤트 이력까지 동등하다고 주장하지 않는다.

**남은 범위:** 321개 개별 이식, 모든 중첩 타임라인·버튼 의미·과도 상태·난수·동시 드래그·입력 순서·장시간 실행. 연속 입력의 표본 검사와 유한 양자수 조합 검사를 ‘모든 입력 조합 완료’로 합치지 않는다. 전체 원본 동등성 플래그는 `false`다.
