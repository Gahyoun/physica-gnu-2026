움직임·그래프·읽기값·CSV가 같은 상태 이력을 읽는다. 전하의 x 위치, 유도전류와 계기 응답, 발전기의 부호 있는 파형과 정류된 계기, 전동기의 정류자 전환을 시간 그래프로 연결했다. 전동기의 sin θ는 회전 위상을 보여 주는 추가 파형이며, 실제 토크를 수치로 측정한 그래프가 아니다.

## 보존한 원본 특성

- 전하 두 개의 질량은 0.05, 계산 시간은 0.1, 세부 계산은 50회다. 전하량 0–100, 자기장 0–100의 원본 눈금과 전하량 제곱의 계수를 따르며 SI 전하량으로 임의 환산하지 않는다.
- 입자 거리 40 이내의 접촉 반발력, 벽 반발력, 속도 제곱의 네 구간별 감쇠를 보존했다. 힘 벡터는 이 계산의 전체 힘을 보여 준다. 원본의 전기력·자기력 개별 화살표 대신 전체 힘을 표시하는 차이가 있다.
- 전동기·발전기는 50단계마다 한 바퀴 회전한다. 원본 루트의 두 프레임당 한 번 계산을 반영해 전하 모형은 5회/s, 회전·유도전류 모형은 4회/s로 표시한다. HTML 배속은 시간 계산값을 바꾸지 않는다.
- 전동기의 |sin θ| ≤ 0.25 전환 구간에서는 원본처럼 전류·힘·코일 자기 방향 화살표를 숨긴다. 원본의 화살표 번호에 따른 전류 전환과 힘 화살표의 중심도 확인했다.
- 발전기의 원본 계기는 |sin θ|를 표시한다. 부호 있는 sin θ 파형은 정류 전후를 비교할 수 있도록 추가했다.
- 유도전류 모형은 `Φ(x) = 1/(x−70)² − 1/(x−10)²`의 차분을 사용한다. 전류의 `trunc(0.5 + value × 100)/100` 규칙과 계기의 0.5 응답 가중치를 보존했다. 음수에서 대칭 반올림으로 바꾸지 않았다.
- 원본 자석의 초기 위치 79.85, twip 좌표, 처음의 계기 과도 응답, 놓은 뒤 50단계 대기, 자동 왕복 범위 넘김도 보존했다. 원본 끌기에서 x<80은 80, x>400은 300으로 이동하는 동작을 대조했다.

## 검사와 한계

[원본 함수 대조](electromagnet-source-report.json)는 **1,957,200회**의 수치·분기 비교를 기록한다. 원본의 101개 전하 눈금을 두 부호 또는 다섯 자기장 눈금과 교차해 300단계씩 계산했다. 유한한 벽·접촉 시작 위치, 회전 1500단계, 자석의 여섯 시작 위치도 비교했다. 원본 스크립트는 공개 저장소 밖의 감사 경로에서만 읽는다.

[실제 Ruffle 대조](electromagnet-runtime-report.json)는 관측한 초기값과 연속 계산 구간, 원본 전하·자기장 슬라이더의 최소·중간·최대, 부호 전환, 전하·자석 끌기, 자석 경계와 자동 이동, 코일 좌표·힘·자기 방향·계기 응답을 비교한다. 원본 SVG와 픽셀 단위 동일성을 주장하지 않으며 원본 좌표에는 0.05 px(1 twip) 양자화를 허용한다.

[HTML 조작 검사](electromagnet-ui-report.json)는 320·768·1360px의 15개 화면에서 입력 끝점, 실제 물체 좌표 변화, 그래프/CSV 상태 일치, 키보드·직접 끌기, 반투명 선, 하단 진행바, 재시작과 라이트/다크를 검사한다. 벡터가 전하의 pointer 입력을 가로막지 않도록 표시 선은 입력을 받지 않는다.

원본의 거리 나눗셈이 정의되지 않는 일치 위치를 피하도록, HTML에서는 두 전하 사이가 원본 위치 눈금 0.05 미만인 놓기를 거부한다. 놓기 슬라이더와 키보드, 정지·초기화·되감기·CSV·시간 그래프는 HTML 기능이다. 끌기 중 전체 모델을 정지한다. 전하를 움직이던 중 놓으면 재생을 이어가며, 자기장 모형과 유도전류는 정지 상태의 끌기 후에도 재생한다. 정지한 eforce2의 놓기는 정지를 유지한다. 끌기를 시작할 때 잡은 위치를 유지하는 것도 HTML 표시 차이다. HTML 위치 입력은 해당 전하의 속도를 0으로 놓으므로 원본의 마우스 이동 속도에 따른 던지기와 모든 연속 이벤트 순서의 동등성은 아직 검증하지 않았다.

누적 개별 HTML 대응본은 **249/518개**, 대기 **269개**다. 전체 Flash의 모든 연속 입력 조합과 이벤트 순서의 대조 완료 표시는 여전히 false다.

회전 모형의 HTML 구간은 1500단계이며 반복은 이 구간의 처음으로 돌아간다. 원본의 루트 타임라인 되감기 이벤트와 모든 재생 경계 이벤트 순서까지 동등하다고 판정하지 않는다.
