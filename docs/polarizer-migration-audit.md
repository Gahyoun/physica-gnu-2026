# 편광판과 도선 흡수 모형 3개

정기수 교수님의 편광판 모형을 원본 그림이나 글꼴을 불러오지 않는 새 SVG와 HTML 조작으로 이식했다. 학교의 파랑·회색 계열을 사용하고 그래프 선 불투명도는 0.65다. 원본은 별도 Ruffle 보관 페이지에서 비교할 수 있다.

| 모형 | 원본 조작·계산 | 리마스터 |
|---|---|---|
| polarizer.swf | 검광판 각도 −90…90°, 3D 시점 드래그, 진폭·세기 비율 | 편광판/검광판과 광원·투과 벡터, Malus 그래프와 수치, 좌표 CSV |
| polarizerwg.swf | 격자 각도 0…90°, 20개 도선, 3D 시점 드래그 | 회색 격자와 수직 투과축, 방향 성분 그래프, 좌표 CSV |
| wiregrid.swf | 55개 전기장 벡터·2개 전자·전류, 225단계마다 방향 전환 | 같은 계산 단계의 장·전자·시간 그래프, 재생/정지/속도/반복, 아래 고정 막대, 현재 시점 CSV |

편광판 두 모형은 각도와 시점에 반응하는 정적 모형이므로 재생 버튼이나 프레임 막대를 만들지 않았다. 세기 비율의 기준은 첫 편광판 뒤의 빛이며 비편광 광원 자체의 세기가 아니다. 격자 방향 성분과 흡수 모형의 화면 변위를 실제 광원의 세기나 정량 흡수율로 해석하지 않는다.

## 원본에서 확인한 특성

- 첫 root 초기값은 각각 60°와 0°지만 슬라이더가 45°와 20°로 바꾼다. 리마스터 초기화는 안정된 슬라이더 기본값으로 돌아간다.
- 원본 `int(0.5 + value)`는 음수에서 0 방향으로 잘라 −90° 끝값이 −89°가 된다. 실제 원본 조작 결과를 기록했고, HTML에서는 명시된 −90°까지 정확히 선택할 수 있다.
- 격자의 투과축 길이는 원본 초기 구성에서 120이고 슬라이더 콜백 뒤에는 100이다. 두 경우를 각각 코드 대조했다. HTML은 슬라이더가 적용된 길이 100을 사용한다.
- 흡수 모형은 12 fps의 두 프레임 루프로 초당 6번 계산한다. 200…224에서 전기장과 전류 벡터를 숨기고, 225에서 다른 방향으로 바꾼다. 수직 편광 구간에는 이전 나란한 편광 구간의 전자 위치와 산란 alpha 4가 남는다. 이 잔류 상태도 보존했다.
- Flash 표시 좌표는 twip(0.05 원본 픽셀), 표시 투명도는 1/256 정밀도를 사용한다. 원본 실행 대조에서는 이 표시 양자화를 구분했다. 새 SVG는 원본 함수의 연속 수치를 그대로 표시한다.
- 원본은 자동 재생하지만 HTML은 정지 상태에서 시작한다. HTML의 0단계는 템플릿 초기 그림 대신 t=0 계산을 바로 보여준다. 시점 조작은 포인터 이동에 직접 반응하도록 바꾸었으므로 원본의 프레임별 누적 드래그 속도와 동일하다고 주장하지 않는다.

## 검증 범위

- 독립 원본 코드 실행: 두 편광판의 모든 정수 각도 상태와 초기 3D 좌표, 흡수 모형 한 주기 450번 계산의 55개 장 벡터·전류·전자·산란 투명도. `polarizer-source-report.json`.
- 실제 원본 Ruffle: 각도 슬라이더의 최소/중간/최대와 시점 드래그, 3D 좌표·투영된 글자 위치; 자연 시계 한 주기 이상에서 두 편광 방향과 두 전환 구간의 표시 변환·전자·투명도. `polarizer-runtime-report.json`.
- HTML 브라우저: 320/768/1360px, 기본/끝 각도와 시점 키·프리셋, 12개 전환 경계, 실제 재생/정지/끝에서 재시작, 아래 막대 고정, 같은 단계 그래프와 CSV, 라이트/다크와 가로 넘침. `polarizer-ui-report.json`.

전체 입력 순서·연속 드래그·모든 픽셀 및 모든 원본의 전수 동등성은 이 유한 검증으로 확정하지 않는다. 각 보고서는 검증한 구현 파일의 SHA-256을 함께 보관한다.
