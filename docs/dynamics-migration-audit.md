## 원본 특성

- springmot2/3의 기본값은 평형이다. 버튼만 눌러도 움직여야 한다고 판정하지 않고, 별도의 질점 변위 조건에서 재생을 검사한다.
- springmot3는 원본처럼 질량 두 개와 양끝 용수철 상수를 공유한다. 첫 정상진동의 두 번째 질점 위치 555는 원본 끌기 상한 550보다 크다. HTML 위치 슬라이더는 이 원본 프리셋도 표시하도록 555까지 제공하되, 직접 끌기는 550으로 제한한다.
- 위치를 새로 놓는 조작은 원본처럼 해당 질점의 속도를 0으로 만든다. 상자 입자의 속도는 에너지 슬라이더를 바꾸면 다시 설정된다.
- 상자 위상공간은 벽을 조금 넘은 위치를 남기고 속도의 부호를 바꾼다. 충돌이 나면 해당 프레임의 나머지 계산을 끝내며, 첫 입자의 충돌 때 두 번째 입자의 이동도 생략한다. 정확한 벽 위치로 강제 보정하지 않았다.
- 진동자의 실제 Ruffle 초기 속도는 0이다. 초기화 코드 일부를 JavaScript 조건으로 해석해서 생기는 추정값을 사용하지 않고, 실제 초기화 순서의 관측값으로 확인했다.
- 빠른 재생은 원본 루트의 두 프레임당 한 번 계산 주기를 반영한다. 연결 진동과 진동자 위상공간은 초당 5회, 상자 위상공간은 10회, 용수철 진자는 원본의 20 ms 타이머에 맞춰 50회다. 원본의 계산 시간 간격은 각각 0.1 s / 0.05 s로 따로 유지한다.
