원본 Ray 클래스의 방향별 전진·굴절·반사·높이 100 탈출·엄격한 충돌 경계·0.00001 위치 보정과 콜백당 광학요소 하나만 처리하는 순서를 따른다. 렌즈 공진기의 평면거울은 원본처럼 초점거리 1e8의 유한값으로 계산하며 화면에는 평면거울로 표시한다. 원본의 사용되지 않는 `RM()` 반환값을 새 계산에 사용하지 않는다. 교재에는 오른쪽 진행 광선의 높이·기울기에 대한 전파와 렌즈 행렬을 LaTeX로 표시했다.

새 SVG는 GNU 파랑·회색으로 표현한다. 오목·볼록렌즈와 거울은 회색 도형, 광선·높이·각도 곡선은 불투명도 0.65다. 광선 선택, 진행·높이·각도 그래프 및 CSV는 동일한 스냅샷을 사용한다. 진행 막대는 장면 아래에 독립 배치하여 재생 버튼의 문구와 프레임 숫자가 변해도 이동하지 않는다. 진행과 무관한 입력형 도식에 프레임바를 추가하지 않는다. 좌표를 미리 계산한 뒤 적은 수의 SVG 경로를 갱신하고, 화면 밖·숨김 탭에서는 재생을 멈춘다.

## 표현·입력 차이와 남은 범위

원본은 즉시 자동 재생하고 100카운터 이후 난수 조건으로 계속 전환한다. 새 화면은 정지 상태에서 시작해 현재 조건의 100단계를 탐색한다. 반복은 동일 조건으로 되돌아가며 난수 전환은 ‘새 광선’으로 선택한다. 조합 모형의 초기 평행광선은 원본 초기값을 유지한다. 렌즈 공진기의 초기 난수는 평균 조건으로 고정해 재현성을 확보했다. 원본 난수 범위의 위치·광선 간격·각도·초점거리를 직접 선택하는 슬라이더, 평행광선 버튼, 그래프·CSV·탐색·속도는 새 학습 기능이다. 조작하면 새 실험으로 다시 시작하며, 연속 난수열의 분포를 동일한 난수 알고리즘으로 재현한다고 주장하지 않는다.

원본 조합 화면의 600폭 밖으로 이어지는 계산 영역을 680폭 SVG로 보여 준다. 실제 계산의 좌표·경계는 원본과 같다. 원본 장식·글꼴·그림·렌즈 도형을 복제하지 않는다. 원본의 화면 가시 픽셀과 새 도형의 픽셀 일치를 검사하지 않는다.
