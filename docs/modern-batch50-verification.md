# 현대물리 15종 · 병렬 50종 묶음

새 SVG 도형으로 에너지띠·고리 파동 6종, 결정구조 6종, 격자 반사·주기적 퍼텐셜 3종을 구현했다. 원본 프레임 그림을 재생하는 방식은 사용하지 않았다. 원작의 개별 계산과 조작을 유지하며, 파랑과 회색 및 그래프 불투명도 0.65를 적용했다. 정적 에너지·결정 화면에는 재생 프레임바를 넣지 않았고, 시간에 따라 진행되는 파동에는 하단 조작바와 화면 밖 일시정지를 적용했다. 주기적 퍼텐셜의 수치 풀이는 별도 worker에서 계산하여 조작 중 화면 작업을 막지 않는다.

원본 AS3 소스의 수치 실행 대조 3,366,249건, 가족별 실제 SVG/조작 화면 45건, 실제 읽기 페이지 45건, 단위 검사 13건이 통과했다. 화면 폭은 320·768·1360이며, 읽기 페이지 검사는 실제 공용 로더를 통과한 mount와 다크 모드 글자 색상을 포함한다.

추가로 15개 원본 AS3 파일의 실제 Ruffle 런타임에서 기본 상태의 공개 수치 1,126건을 대조했다. 별도의 빈 Sprite 관측자를 메모리 사본에 추가했으며, 원본 root 클래스·ABC·타이머·헤더 및 원래 모든 태그의 바이트가 그대로임을 검사했다. KP의 공개 극값과 고리의 선택 에너지/시간, 결정의 원자 중심·반경 일부, Bragg 타이머 위상, QuantumSolver의 이미 저장된 에너지 값만 읽었다. QuantumSolver 접근자는 원래 저장된 private scalar를 반환하는 순수 getter이며 fitting/reset/draw 계산은 호출하지 않았다. 이 런타임 보고서는 기본 수치 및 제한된 타이머 표본에 한정된다. 모든 입력 조합·연속 입력 이력·모든 파동 프레임의 런타임 동등성은 아직 입증하지 않았다.

각 증거의 구체적 범위와 현재 파일 해시는 JSON 보고서에 저장되어 있다. 정확한 15개 ID와 이 담당 범위에서 아직 남은 36개 ID는 `modern-batch50-verification.json`에 기록했다. 공유 카탈로그와 배포 기록은 통합 담당이 갱신한다.

CI에서 사설 원본 추출 캐시 없이 실행 가능한 검사:

```sh
node --test tools/modern-batch50-kp-physics.test.mjs tools/modern-batch50-crystal-physics.test.mjs tools/modern-batch50-periodic-physics.test.mjs
```

원본 수치 소스 대조는 `preview/private-scripts`가 필요하다. 실제 런타임 관측은 로컬 미리보기 서버, Playwright, FFDec 및 playerglobal SWC가 필요하며 일반 공개 CI 완료 조건으로 사용하지 않는다. 원본 소스 대조·native UI·실제 원본 런타임의 증거 범위는 서로 구분한다.
