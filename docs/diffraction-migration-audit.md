## 보존한 계산과 표현 차이

프레넬 적분의 0.1 간격 누적 표와 Simpson 가중치를 따른다. 코르뉴 세부·회절은 0.0001, 정적 코르뉴 나선은 0.001 적분 간격이다. 누적 표 사이 잔여 구간은 원본처럼 오른쪽 직사각형 합으로 더하며 분석식·보간으로 바꾸지 않는다. 양·음 부호와 무한대의 ±0.5는 유지한다. 같은 계산을 여러 번 수행하지 않도록 표와 결과를 제한된 크기의 캐시에 저장한다.

회절의 세기는 `[(C₂−C₁)²+(S₂−S₁)²]/2`, 진폭은 그 제곱근이다. 칼날의 열린 끝은 (0.5, 0.5)다. 회절 그래프의 x축은 적분 구간 중심이며 SI 길이 단위가 아니다. 밝기는 `min(255, round(51.2*|E|²*exposure))`, 노출 단계는 1·5·25·125·625를 따른다. 원본처럼 시작 범위는 폭에 따라 −12−폭/2에서 12−폭/2로 바뀌며 칼날은 −12–12다. 클래스의 incrementOrDigit=1.5는 실제 radix=0.05이므로 HTML도 0.05 입력 눈금을 사용한다. 원본 입력값은 `round(value/radix)*radix`로 정규화한다. trace 문자열에서 없어진 이진 소수의 끝자리는 이 원본 연산과 경계 clamp로 복원해 비교한다. 0.1 표 경계에서 극소 입력 차이가 잔여 적분 한 항의 차이로 이어질 수 있으므로 검사 허용치를 일괄 넓히지 않는다.

원본 회절은 임의 폭 1.5–4.4로 자동 재생을 시작하고, 최초 노출 내부값 2와 슬라이더 표시 1이 다르다. HTML은 재현 가능하게 폭 2, 노출 1에서 정지해 시작한다. 원본의 25ms 간격 600개 공간 스캔 위치를 제공하며 진행바는 아래에 고정한다. 모든 위치에서 전체 공간 곡선과 밝기 띠를 미리 표시하고 현재 위치를 점으로 표시한다. 원본은 스캔한 열을 누적해 그린다. 원본 끝점 문자열의 (C₂,C₂) 오기를 (C₂,S₂)로 고쳤다. 스캔 슬라이더·수치·벡터·그래프 점은 동일 상태를 공유한다. 스캔 중 시작 위치 입력은 연속값을 표시하고, 수동 입력으로 전환하면 원본 0.05 눈금과 반올림한 범위로 돌아간다. 반복·속도·되감기와 CSV는 HTML 추가 기능이다. CSV는 원본 클립보드 버튼을 그대로 재현한 것이 아니라 출처·현재 입력·현재 상태와 수치 표를 함께 저장한다.

위상자 합은 원본의 유한 N개와 각도 상수 3.1415926, 결과 세기·각도 0.1 자리 반올림을 유지한다. 세기를 반올림해 0으로 표시하는 경우 각도도 원본처럼 0이다. 연속 슬릿의 sinc 근사로 대체하지 않는다. 원본 위상 슬라이더의 트랙 끝은 명목 최대 4000°보다 높은 4010°까지 도달한다. 원본 실행 보고서에 이를 별도 경계 조작으로 기록하며 HTML은 명목 입력 범위 0–4000°로 제한한다.

구역판은 56개 원판의 `sqrt(n)*lambda/10` 배율과 엄격한 `<300` 숨김 조건을 보존한다. 그림 크기는 보기 좋게 정규화했으며 실제 nm 길이·원본 픽셀 반지름으로 표시하지 않는다. 겹친 원판은 큰 것부터 그려 반대 투과 순서를 표현한다. 파장·배율 곡선은 같은 입력값이다.
