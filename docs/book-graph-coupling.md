# 보충 탐구의 그래프–물리 모형 연결

2026-10-10. 대상은 교재의 독립적인 보충 탐구 79종이며, 원본 Flash의 개별 이식과는 별도의 탐구 모형이다.

카르노 효율의 고정 기준선 η = 1 − Tc/Th에 현재 온도비의 선택점을 추가했다. 동일한 Th/Tc 상태에서 Qh=1, Qc=Tc/Th, W=1−Tc/Th를 계산하고 열 흐름 도식의 폭·수치를 갱신한다. 재생하면 흐름 방향을 표시하는 점이 이동한다. 이 이동은 실제 피스톤 운동이나 카르노 순환의 시간 해석이 아니다. 흐름 단계는 3단계 범위 안에서 반복하며, 초기화·탐색·일시정지를 지원한다.

추가 보완:

- 25종의 그래프에 입력과 연결된 선택점 추가. 고정 관계식은 유지하고 선택한 좌표를 표시한다.
- 기체 피스톤, 융해 비율, 축전기 판 간격, s/p 반사율, 편광판 투과축, 음원 파면, 열출력 분배, 무한 우물 길이의 입력 연동 도식 추가.
- 회전 코일의 방향과 자기선속·기전력의 시간 그래프 연결.
- 정규화 좌표 x/L에서 길이가 바뀌어도 곡선 모양이 같은 무한 우물에는 물리적 길이와 에너지를 별도로 표시.
- 시간에 따라 변하지 않는 평형 관계와 스펙트럼은 입력으로 조작하고 재생 막대를 추가하지 않는다.
- 경상국립대 파랑·회색 계열과 기존 그래프 선 투명도 0.65 유지. 도식은 SVG로 구성하고, 좁은 화면에서 도식 내부를 스크롤한다.

검증:

- `book-coupling.test.mjs`: 25종 선택점의 함수값 일치, 카르노의 허용 온도 조합 2,430개에서 에너지 보존, 도식의 입력 반응, 전체 보충 탐구의 조작 영향 검사.
- `book-coupling-browser-check.mjs`: 79종, 각 입력의 최소·기본·최대값, 실제 SVG 선택점과 함수값 비교, 움직이는 19종의 실제 그림 변화와 일시정지 확인. 모바일 320px·태블릿 768px·PC 1360px에서 페이지 가로 넘침 검사.
- `book-browser-check.mjs`: 566개 읽기 페이지, 79개 보충 탐구, 슬라이더 경계 검사 308회 통과.
- `book-apparatus-browser-check.mjs`: 추가 도식 9종 × 세 화면 크기 = 27회 다크 모드 검사, 카르노 열 흐름의 반복 범위와 움직이는 점의 단계 일치 확인.
- `coupled-browser-check.mjs`: 운동 화면과 공간/시간 기록점의 기존 동기화 회귀 검사.
- 기존 Flash HTML 518종: 세 화면 크기 재생 회귀 검사 1,554회 통과(실패 0, 브라우저 오류 0). 이는 재생 회귀 검사이며 원본의 모든 입력 조합 대조가 아니다.
- 수식 페이지 571개 × 세 화면 크기 = 1,713회 렌더링 검사 통과.
- 전체 Node 테스트 682개 통과.

이 검사는 보충 탐구의 조작과 연결 상태를 검증한다. 연속적인 모든 입력 조합이나 모든 원본 SWF 런타임의 동등성을 인증하는 것은 아니다. 실제 브라우저 결과와 코드 해시는 `book-coupling-ui-report.json`에 기록한다.
