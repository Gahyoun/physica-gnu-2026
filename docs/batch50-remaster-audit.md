개별 source/artwork 보고서와 UI 보고서는 현재 파일 SHA-256을 기록한다. 새 입력 조작·움직임·정지·초기화·CSV를 320/768/1360 폭에서 확인한다. 교재 실제 자동 초기화도 확인하여 독립 테스트 화면에서만 작동하는 구현을 배제했다. 전체 [재생 보고서](playback-ui-report.json)는 현재 HTML 대응본 399개×3폭을 검사한다. 숫자가 증가하는 것만으로 통과하지 않고 SVG 도형의 실제 변화, 정지, 재개, 끝에서 재생을 확인한다.

## 실제 원본 실행과 다른 증거

- 광학: 실제 원본 AS3의 자연 광선 배열·교차 횟수 97,276개를 제한된 시간 구간에서 비교했다. 독립 소스 실행의 1,553,380개 비교와 다른 증거다. 원본 ToyLens의 1픽셀 테두리를 포함한 광선 경계값을 반영했다.
- 일반물리: 실제 원본 공개 격자 선택점, 기본 회절 readout, 자연 파면의 모든 광선 5,703개를 비교했다. 원본의 무작위 초기조건을 읽어 비교하며 강제 대체하지 않았다.
- 현대물리: 실제 원본의 기본 KP 수치, 고리 선택 에너지/시간, 결정의 공개 좌표·반경, Bragg 시간, 저장된 양자 에너지의 읽기 전용 getter 1,126개를 비교했다. 전체 그래픽·모든 입력 조합 대조는 아니다.
- 핵물리: 원본의 자연 158프레임과 ITER 설명 버튼의 두 정지 상태를 관찰했다. AS3는 ENTER_FRAME과 FRAME_CONSTRUCTED를 함께 관측해 원래 5초 타이머의 순간적인 2번 프레임도 기록했다. 원본 태그·클래스·타이머 바이트를 보존했다. 이것은 수치 솔버 동등성 증명이 아니다.

핵물리의 원래 입자 위치·반경은 private 원본 프레임 내보내기와 별도 대조한다. 내보낸 SVG·원본 그림을 교재에서 재생하지 않는다. ITER와 원자로는 새로 그린 단순화된 도식이다. 핵분열 수율은 원본 교육 그림의 곡선을 수치 표본으로 옮긴 것으로, 실험 데이터가 아니다. 무거운 하전입자 원본의 첫 5초 대기는 새 명시적 재생 버튼으로 대신한다.

## 재생·표시 수정

광선은 내부에 남은 비율이 작아져 프레임 한도보다 일찍 자연 종료할 수 있다. 이 종료 상태를 기록해 다음 재생이 초기 파면에서 시작하도록 했다. 잠시 재개한 뒤 250ms 이내에 정상 종료되는 경우에는 실제 단계 증가·도형 변화·명시적 완료를 확인하며, 버튼이 계속 일시정지 상태여야 한다고 요구하지 않는다.

종료 직전 버튼 상태 확인과 클릭 사이의 경합도 검사에서 제거했다. 같은 브라우저 이벤트 턴에서 현재 버튼이 일시정지일 때만 멈추며, 원본의 자연 종료를 재생 장애로 세지 않는다. [시간별 독립 재현](optics-batch50-resume-investigation.json)과 [구면경계 반복 재현](optics-batch50-resume-spherical-investigation.json)을 남겼다.

광원·초점 표시와 회절 광원/벽 끌기의 클릭 오프셋을 복원했다. 정적 모형에는 재생·프레임바를 넣지 않았다. 움직이는 모형의 진행 막대는 도형 아래에 고정하고 화면 밖이나 숨겨진 탭에서 계산을 멈춘다. 시간 그래프/파면은 GNU 파랑·회색 계열, 선 투명도 0.65를 적용하고 다크모드 글자색을 실제 사이트 토큰에 연결했다.

모든 연속 입력, 드래그 위치, 긴 시간과 이벤트 순서를 전수 대조한 완전 동등성은 여전히 미완료다. 위 수치·프레임·UI 각각의 유한 범위를 서로 대체하거나 합쳐 전수 완료로 표시하지 않는다.
