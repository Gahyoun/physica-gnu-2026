# Final 69 — optical 20

These twenty entries are separately authored HTML controls and freshly drawn SVG primitives. No original bitmap, exported frame sequence, Ruffle surface, or copied original artwork is used as the remaster. The original individual optical calculations were ported; the preserved originals remain separately available for comparison. Full source URLs, original SWF SHA-256 and reading-page IDs are recorded in `src/native-optics-final69.json` to disambiguate reused filenames.

## Verification

- Independent source evaluation: **20/20**, **6,505,341** finite numeric comparisons, maximum absolute error **0**. Original ActionScript mathematical bodies are parsed into a test-only dynamic-scope interpreter; production uses a separate lexical member transformation. Original component construct properties are included in the captured source hashes. Shared display plumbing is explicit; frame temporaries and display allocation metadata are excluded, with skipped counts recorded. Every pupil sample is mandatory.
- Actual original Ruffle runtime: **20/20** bounded checks, **4,850** measured numeric/placement/frame values. Original tag bytes, ABC/document classes and timers remain unchanged; only a diagnostic child reads public fields. Native calculations are compared at the naturally observed clock or finite ray distance. Random lens parameters are read once to match the actual original input condition; evolving ray coordinates are never copied into the native calculation.
- Original crystal MovieClip placements are quantized to one SWF twip (1/20 pixel). Their actual raw discrepancy against the continuous native source calculation is retained, maximum **0.04953884165810507 px**, with an explicit **0.05 px** placement tolerance. This tolerance does not apply to other mathematical fields.
- Actual reading-page UI: twenty entries at **320, 768, 1360 px**, including SVG mount/geometry, original sliders, keyboard 3D view changes, original image/voltage buttons, polarizer state changes, and moving models' play/pause/resume/end replay. Final current hashes are recorded in `optics-final69-ui-report.json`.
- Eight physical regression tests pass: Airy scaling/zero, pupil sagitta/focus, Zernike boundaries, total reflection critical angle/end replay, coupled crystal motion, Jones normalization, evolving Poincare vectors and genuinely static geometry.

## Scope and limits

This is a finite source and runtime audit, **not** every possible continuous input combination or every unbounded interaction history. Numerical source proof, actual original runtime observation and new SVG UI checks remain separate reports. Missing original public fields are listed rather than filled with zero.

`rp2.swf` exposes its three control values and resolved/unresolved text to the diagnostic child but keeps the numerical diffraction curve fields inaccessible. Its actual original runtime proof is limited to those input values and classification; its Bessel/Airy curve numbers are independently source-checked and tested, not claimed runtime-observed. The AS3 string classification comparison is recorded separately from numeric counts.

The static original polarizer has two stopped frames. Actual original button clicks produced frame **2 → 1**; the remaster uses explicit SVG absorption/transmission views, without a fictitious animation bar. The static Kerr cell retains its construct-time **isON=true** state and its original voltage toggle; the real original toggle produced both false and true states. The native UI retains this initial value and exposes the switch instead of filtering it out as a play button.

Original undefined display-only calls (including scattering `remakeWave`, forward-declared image canvases and placeholder plates) are adapter no-ops. Optical calculation methods are retained. Nonfinite source display paths are omitted explicitly instead of invented numeric coordinates.

Seven genuinely animated models use the original timestep/calculation and a fixed timeline below the SVG, default fast plus a slow option. Replay clears a completed state and redraws immediately. Offscreen/hidden-page rendering pauses. Thirteen static models have controls or view changes and no play bar. Light/polarization uses GNU blue with 0.65 line opacity; optical references and crystal spring paths use gray.

## Reproduction

With original scripts extracted to the ignored `preview/private-scripts/<id>/scripts` directories and the local reading-page server available on port 8775:

```sh
python3 tools/optics-final69-capture.py
node --test tools/optics-final69-physics.test.mjs
node tools/optics-final69-source-check.mjs
node tools/optics-final69-runtime-check.mjs
node tools/optics-final69-ui-check.mjs
```

The runtime/UI tools need Playwright, local browser execution and the bundled FFDec compiler/playerglobal SWC. Original decompiled scripts, compiled diagnostic SWFs, and UI screenshots remain in ignored preview storage, not public textbook pages. Integration exports `opticsFinal69Specs` and `mountOpticsFinal69`, prefix `opticsfinal69-`.
