# 편광의 복소표현과 존스 벡터 예시 · 2026-10-09

정기수 교수님의 `complexrepV2.swf`와 `jonesrepresent.swf`를 독립적인 HTML/SVG로 구현했습니다. 원본 그림·프레임 이미지를 불러오지 않으며 원본 파일은 별도의 Ruffle 목록에서 유지합니다.

- [편광의 복소표현](../lesson-5-3-5-1.html#native-jones-flash-2ab186387abfa7fd): 원본의 x,y=-2.5…2.5/0.5에 해당하는 121개 복소좌표와 정규화 편광 궤적입니다. J=(1,ζ)/√(1+|ζ|²), ζ=x+iy의 실수부 전기장을 표시합니다. 원본은 scale=20, 75ms마다 위상 시각 t+=0.2입니다.
- [존스 벡터의 예](../lesson-5-3-5-2.html#native-jones-flash-d58c692d9b863103): 원본의 12개 선편광·원편광·타원편광 예시를 유지합니다. 음의 두 번째 진폭과 225° 위상을 포함하며, 두 성분을 √(a²+b²)로 정규화합니다. 원본은 scale=50, 50ms마다 t+=0.1입니다.

원본 두 파일에는 조작 버튼이 없으며 자동으로 무한 재생합니다. 새 화면은 정지 상태로 시작하고, 0…600 콜백의 시각 선택·재생·정지·끝에서 다시 재생·선택적 반복·느리게/4배를 추가합니다. 반복은 이 유한 표시 창을 초기화하므로 원본의 연속 무한 시각과 같다고 주장하지 않습니다. 초기 템플릿 마커가 남는 원본 첫 순간 대신 t=0의 계산된 위치를 표시합니다. t는 원본의 위상 시각으로, 실제 경과 초와 구별해서 표시합니다.

새 선택 상자와 SVG 도식의 클릭·Enter·Space 선택으로 예시를 확대합니다. 선택은 원본 예시의 진폭·위상을 바꾸지 않고 현재 시각과 실행 상태를 유지합니다. 전체 예시의 움직이는 점, 확대 도식의 점·전기장 벡터·성분 투영과 선택 예시의 시간 그래프는 같은 시각입니다. CSV는 선택한 예시의 현재 단계까지만 내보내며, 역방향 탐색 후 미래 이력을 남기지 않습니다. GNU 파랑·회색, 그래프 선 불투명도 .65와 고정 하단 진행바를 사용합니다. 궤적은 초기 캐시하고 시간 이력은 선택 변경 때만 계산합니다. 화면 밖과 숨긴 탭에서 재생을 멈춥니다.

## 검증 범위

- 독립 원본 함수: 원본의 모든 궤적 그리기 명령, 121개/12개 표시점의 0…600 모든 콜백 시각 및 여섯 추가 위상·장시간 시각을 비교합니다. 존스 예시의 열두 좌표축 위치도 포함합니다. 167,650개 수치 비교가 허용 오차 1e-8 내에서 통과했습니다.
- 실제 원본 런타임: 원본 시각을 강제하지 않은 자연 재생 30창씩, 전체 133개 표시점·원본 위상 증가량·scale·열두 좌표축을 비교했습니다. 표시 좌표의 한 twip(.05px) 양자화를 허용합니다. 원본 파일의 해시를 확인하고 진단 사본에 읽기 관찰자만 추가합니다.
- 새 웹 UI: 320/768/1360px, 데스크톱의 121개/12개 전체 선택과 모바일·태블릿의 경계 선택, 같은 시각의 전체 표시점·확대 점·그래프 점, 클릭/키보드 선택, 재생 중 선택 유지, 정지·재개·끝·반복·역방향 탐색, 현재 CSV, 새 벡터만 사용, .65 선, 테마와 가로 넘침.

원본에 없는 선택/재생 버튼을 원본 조작이라고 기록하지 않습니다. 원본의 모든 무한 시각·픽셀·이벤트 순서 전수 동등성을 완료한 것은 아닙니다. `jones-source-report.json`, `jones-runtime-report.json`, `jones-ui-report.json`에 수치와 범위를 따로 기록합니다.
