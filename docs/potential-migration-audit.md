## 원본 계산과 추가 기능

높이 모형은 원본 콜백당 10회 갱신을 따른다. 이전 높이들을 먼저 저장한 뒤 네 이웃 평균과의 차이를 계산하고 `v = damping*v + force/200 − gravity*0.05`, `v -= 0.1*v`, `y += v` 순서로 적용한다. 경계 공과 잡고 있는 공은 고정한다. 감쇠 계수는 평소 0.999, 잡고 있을 때 0.9다. 중력이 있으면 이웃 평균보다 10 낮은 평형을 향한다.

원본은 모든 높이 0으로 시작한다. HTML은 움직임을 바로 볼 수 있도록 왼쪽 경계 하나를 100으로 두며, ‘모든 높이 0’으로 원본 초기 상태를 제공한다. HTML 높이 입력은 −300–300으로 제한하지만 원본 드래그는 같은 제한이 없다. 시점 회전·기울기, 공 선택·키보드 높이 조절, 시간 그래프·CSV·진행바는 추가 기능이다. HTML은 드래그 중 자동 재생을 멈추고 포인터 이동마다 한 콜백을 계산한 뒤 놓으면 재생하므로 원본의 비동기 드래그 시간 이력 전체와 같다는 뜻은 아니다. 500단계 재생 구간도 원본의 장시간 자동 초기화 분기와 다르다.

전기력선은 원본의 다섯 전하 분기, 15개 선분, 분기별 10/12회 미소 이동, 원본의 각도 상수와 이동 간격을 보존한다. 오른쪽 전하는 −1이다. 음전하에서 역방향으로 추적한 선은 화살표를 반대로 표시해 전기장 방향을 나타낸다. 같은 전하로 계산한 `y = 240`의 정규화 전위 단면은 학습용 추가 그래프이며 원본에 있던 곡선으로 세지 않는다. 원본 선분 그림의 픽셀 모양·서체는 보존하지 않는다.

입자 모형은 원본의 질량 0.01, 시간 간격 0.02, 3회 세부 적분, 벽·장애물·입자 반발력과 연산 순서를 따른다. 장애물 접촉력은 원본처럼 마지막으로 걸린 장애물 값으로 덮어쓰며 단순 합산으로 바꾸지 않았다. 중력 계수는 원본의 `9.8*sin(angle/180*3.1415926)`이다. y>560에서 입자를 위로 재주입하고 첫 통과 때 집계 카운터를 초기화한다. 50회 갱신마다 원본 집계 눈금이 증가한다. 아래 그래프는 이 눈금과 통과 횟수이며 SI 전류가 아니다.

HTML 난수는 재현 가능한 시드를 사용한다. 원본 Math.random의 실제 시퀀스와 모든 확률 궤적이 같다는 주장은 하지 않는다. 원본은 위치를 그린 뒤 재주입하지만 HTML은 재주입 후 수치 상태를 그리므로 한 콜백의 표시 순서 차이가 있다. 입자 중심이 정확히 겹친 특이 상태는 HTML에서 나눗셈을 건너뛰어 NaN을 방지하며 원본 동등성으로 세지 않는다. HTML 1000단계 재생 구간, 속도·반복·CSV·되감기는 추가 기능이다. 경사각·체크박스 변경 시 위치와 원본 집계 카운터를 유지하면서 HTML 진행 구간을 새로 시작한다.

원본 집계 간격의 표본에 현재 통과 횟수의 끝점을 추가해 장면과 최신 값을 연결한다. 되감기 시 현재 단계까지만 그리고 첫 통과 후 초기화된 집계 구간을 사용한다. 미래 이력이나 초기화 전의 집계 눈금이 축·곡선에 남지 않도록 검사했다. 50단계 체크포인트에는 난수 상태를 함께 보존한다. 재생은 수동으로 시작하며 화면 밖·숨겨진 탭에서는 중지한다. 진행바는 장면 아래에 두고 상태 문장의 높이를 확보한다.

## 검사 근거와 한계

[독립 원본 함수 대조](potential-source-report.json)는 **16,257,810회**를 기록한다. 평균 모형 30개와 라플라스 모형 972개 조건에서 각 공의 초기 높이 −300/100/300, 감쇠 0.999/0.9, 중력 OFF/ON을 조합해 각각 100콜백의 모든 높이·속도를 비교했다. 전기력선의 다섯 전하 분기와 모든 선분 위치·길이·각도·표시 여부도 비교했다. 입자는 난수 시드 3개 × 경사각 3개 × 장애물 2상태 × 입자 충돌 2상태의 36조건을 각각 300콜백 실행해 10개 입자와 집계·난수 상태를 대조했다. 최대 절대 오차는 약 1.14×10⁻¹³이며 입자 모형 비교 오차는 0이었다.

원본 스크립트는 비공개 캐시에서 독립 VM으로 실행한다. 숫자 계산식을 유지하고 이름 기반 공 조회를 직접 객체 조회로 바꾸며 암묵적 임시 변수와 불변 상수를 지역화해 실행 비용을 줄였다. 그림 배치 함수는 수치 비교에서 제외했다. 확률 모형의 원본 함수에는 같은 재현용 난수열을 공급한다. 추출된 ActionScript나 원본 프레임 이미지는 HTML 화면·배포물에 포함하지 않는다.

[실제 Ruffle 대조](potential-runtime-report.json)는 **15,635회**의 수치 비교와 실제 포인터 조작을 기록한다. 평평한 초기 상태, 경계 높이 60의 실제 드래그 후 운동, 7×7 중력 OFF→ON→OFF, 실제 전하 슬라이더 다섯 값, 장애물·입자 충돌 체크박스와 경사각 10/45/90, 원본 재생·정지를 확인했다. 높이 모형의 인접 관측 사이에는 0회 또는 1회 콜백이 있었는지 상태 변화로 구분한다. 전기력선 Flash 좌표의 twip 반올림·절삭에는 0.050001 px 허용 오차를 적용한다. 입자는 난수·통과 수가 변하지 않은 실제 비영 운동 구간만 다음 수치와 비교하고 확률 충돌·재주입 구간은 제외해 기록했다.

[HTML 화면 검사](potential-ui-report.json)는 320·768·1360 px의 **12개 화면**에서 입력 끝점, 실제 SVG 운동·정지·끝 재생, 직접 경계 드래그, 원본 평평한 상태, 카메라 회전, 체크박스, 상태·CSV·체크포인트 되감기의 일치, 반투명 선·라이트/다크·아래 진행바를 검사한다. 입자 그래프는 끝까지 이동한 후 과거로 되감아 현재 집계 끝점과 미래 이력 제거도 확인한다. 체크포인트 기대값은 같은 브라우저의 순수 계산 함수로 생성하며 Node와 브라우저 간 초월함수의 마지막 비트까지 같다고 주장하지 않는다. 별도 물리 검사는 평균 평형·중력 차이, 선형 높이장의 보존, 입자 충돌의 대칭 운동량과 재주입 초기화를 다룬다.

누적 HTML 대응본은 **258/518개**, 개별 이식 대기는 **260개**다. 모든 연속 입력·드래그 경로·장시간 난수 이력·렌더링 순서의 전수 동등성을 완료로 표시하지 않는다. `fullEquivalence`는 false로 유지한다.
