## 계산과 원본의 특성

결정: 흡수 슬라이더 s/2000을 계수로 사용합니다. 120개의 전기장 선분, 6개 결정 면, 16개 화살표, 네 좌표/입사광 표시를 새 벡터로 구성했습니다. 내부 위상 L/10과 외부 위상 (300+4i)/15, 길이 200에서의 감쇠 exp(-200β)를 유지합니다. 출사면의 직교 성분과 공간 그래프가 같은 계산 단계에서 움직입니다. 원본처럼 흡수지수 변경은 시각과 재생 상태를 초기화하지 않습니다. 원본 슬라이더 초기값 50이 안정된 상태를 기본값으로 사용합니다. root 10fps의 두 프레임 반복에 따른 5회/초 갱신을 따릅니다.

합성: 선편광 기저와 원편광 기저의 두 별도 합성 패널입니다. 같은 빛을 기저만 바꿔 표현하는 화면이라고 설명하지 않습니다. 두 진폭 0–1.5/0.05, 상대 위상 -180–180°/5°, 원본 50ms 타이머의 t+=0.05와 원편광 계수 1/1.414를 유지합니다. 원본의 6개 궤적, 6개 전기장 점과 벡터, 평행사변형 합성을 재작성했습니다. 입력 변경은 시각 0으로 되돌립니다. 궤적과 시간 자료는 입력 변경 시 캐시하고, 재생 중에는 현재 점/벡터와 그래프만 갱신합니다.

두 화면 모두 GNU 파랑·회색과 선 불투명도 .65를 사용합니다. 하단 고정 시각 선택, 느리게/4배, 정지·다시 재생, CSV, 그래프는 새 학습 조작입니다. 화면 밖이나 숨겨진 탭에서는 재생을 멈춥니다. 결정의 시점 변경은 누적 포인터 이동/키보드 방식으로 접근성을 보강하며 원본의 누름 유지 방식과 같다고 주장하지 않습니다. 결정은 마지막 단계 5000을 유지하고, 원본은 다음 콜백에서 정지/0으로 초기화합니다. 합성 원본은 자동으로 무한히 재생하며 재생 버튼이 없습니다. 새 화면은 일단 정지 상태로 시작해 원본 위상 시각 0–20 창을 제공하고, 선택한 반복은 이 창을 재시작합니다. 광원의 SI 세기나 실제 물질 상수를 나타내지 않습니다.

## 검증 범위

- 독립 원본 함수: 결정의 101 입력×51 시각 표본과 기본 입력의 5001 단계, 모든 전기장/출력 좌표 및 원본 6자리 세기 표시. 편광 합성의 31×31×73=70,153개 입력 조합×5 시각, 401 기본 단계, 27 경계/기본 조합의 6개 원본 궤적 좌표. 허용 오차 1e-8.
- 실제 원본 Ruffle: 결정 슬라이더 최소/중간/최대, 재생·정지·재생 중 입력과 시점 이동, 원본 전기장/결정 좌표. 합성 세 슬라이더의 최소/기본/최대 실제 드래그와 자연 타이머 시각의 6개 점 좌표. 원본 표시 좌표의 한 twip(.05px) 양자화 허용. 진단 사본에는 읽기 관찰자만 추가하고 입력·시각을 강제하지 않습니다.
- 새 웹 UI: 320/768/1360px, 슬라이더 경계, 재생·정지·재개·끝 재생·반복·역방향 시각 선택, 하단 진행바 고정, 같은 계산 단계의 출력 벡터와 그래프 점, 현재 자료 CSV, 벡터 전용 표시, 테마·가로 넘침.

원본 함수의 유한 입력 격자 대조와 실제 원본 이벤트 대조는 구별합니다. 원본의 모든 입력·무한 시각·모든 이벤트 순서·픽셀 전수 동등성을 완료한 것은 아닙니다. 상세 결과는 `dichroic-source-report.json`, `dichroic-runtime-report.json`, `dichroic-ui-report.json`에 기록합니다.
