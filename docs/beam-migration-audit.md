원본 BeamFtn의 반경·진폭·위상과 렌즈 변환, BeamGraph의 2 px 빔 경계·51점 등진폭 곡선·포물선 파면 좌표를 독립적으로 재구현했다. 선은 GNU 파랑·회색과 불투명도 0.65, 구조물은 회색이다. SVG 손잡이를 끌거나 접근 가능한 슬라이더로 같은 값을 바꿀 수 있다. 입력 때만 갱신하는 도식이므로 재생·시간·프레임바를 생성하지 않는다.

아래 그래프는 현재 광학계와 같은 상태에서 계산한 빔 반경과 중심 진폭이다. 실선은 반경, 점선은 입사 빔 중심 진폭을 기준으로 한 상대 진폭이며 각각의 최대 눈금을 표시한다. 데이터 CSV는 원본 화면의 5 px 격자에서 진폭과 위상을 담으며 현재 입력·모델 상태를 함께 기록한다. 위상은 각 구간의 빔 허리를 기준으로 한 원본 `getPhase` 값이며, 구간 번호를 함께 저장한다. 렌즈 앞뒤의 절대 위상 연속성을 검증한 데이터는 아니다.

## 서로 다른 검증 근거

- [원본 함수 비교](beam-source-report.json): **194,815회**. 원본 비공개 ActionScript를 별도 VM에서 실행했다. 기본 빔 경계·등고선·각 영역의 파면 81개, 진폭·위상·렌즈 변환 표본, 입력별 11값과 선택된 초점/반경 조합을 확인했다. 공진기는 기본 파장에서 곡률반경 **191 × 91 = 17,381쌍**의 안정 분기와 해당 모드 값을 비교했다.
- [실제 원본 실행](beam-runtime-report.json): **736회**. Ruffle에서 원본 슬라이더를 실제 끌고 최소/기본/최대에 도달시킨 뒤 root와 BeamGraph 값을 읽었다. 초점·반경·렌즈의 드래그, 체크박스, 공초점과 불안정 경계도 포함한다. 수치 허용치는 1e-7이며 원본 소수 위치의 포인터 도달은 화면 픽셀 해상도 때문에 .550001 px로 별도 판정한다. 입력을 덮어쓰거나 원본 수식을 바꾸지 않았다.
- [HTML 화면 검사](beam-ui-report.json): **12건 = 4종 × 320/768/1360 px**. 입력 끝값, 실제 SVG 손잡이 끌기, 같은 상태·그래프·CSV, 파면/등고선 전환, 다크 모드, 벡터 전용 화면과 정적 프레임바 제거를 확인했다.
- 전체 HTML 재생 회귀 검사는 [playback-ui-report.json](playback-ui-report.json)에 별도로 기록한다.

## 표현과 입력의 차이 및 남은 범위

원본의 구형 임베디드 슬라이더·글자·색을 현대적인 HTML 조작과 SVG로 바꿨다. 원본 드래그 범위는 유지하고 값은 0.05 px 눈금으로 입력할 수 있다. 렌즈 2종의 파면·등고선 표시 전환은 새 편의 기능이며 원본은 두 표현을 상시 표시했다. 단일 렌즈 원본의 파장 0.2 이하에서 파면을 생략하는 조건을 유지한다. 5 px CSV는 원본의 클립보드 기능을 내려받기 방식으로 확장했고, 렌즈·공진기의 데이터 내려받기와 하단 연동 그래프는 추가 기능이다.

공진기의 불안정 분기는 원본에서 이전 안정 모드의 값과 그리드를 일부 남길 수 있다. 새 화면은 안정한 모드가 없음을 명시하고 이전 반경·레일리 길이를 숨긴다. 원본의 장식 마스크·글자·그림 영역은 현대적인 반응형 SVG 영역으로 다시 배치했으므로 픽셀 일치를 주장하지 않는다.

공진기의 모든 파장 × 곡률반경 조합, 모든 연속 끌기·동시 입력·이벤트 순서, Adobe Player 자체와의 동등성은 미완료다. 보고서의 `fullEquivalence=false`를 유지한다. 원본 함수 검사와 HTML 화면 검사를 원본 런타임 전수 대조로 합산하지 않는다.
