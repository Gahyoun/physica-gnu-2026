# 광선·스펙트럼·상대성이론 25개 이식 기록

정기수 교수님의 원본 Flash 25개를 독립 HTML 조작과 새 SVG 도형·텍스트로 이식했다. 원본 SWF를 그림이나 프레임으로 확대하지 않는다. 원본은 `flash.html`에서 별도로 비교하며 파일 바이트와 해시를 보존한다.

## 원본별 대응

| 분류 | 원본 프로그램 | 새 도식·조작 |
|---|---|---|
| 광선 작도 4개 | convex1, concave2, concavemirror, convexmirror | 광선 생성 순서, 연장선과 상, 재생·단계 이동 |
| 확대경 2개 | magnifier, magnifier2 | 바로 선/뒤집힌 배율, 렌즈 끌기·키보드·위치 입력 |
| 스펙트럼 3개 | spectra_He, spectra_Ne, spectra_origin | 개별 원소의 원본 파장, 방출/흡수 전환, 선택 선의 수치 |
| 복사·색·상변화 3개 | blackbody, testcolor, vanderphase | 온도/파장, RGB와 복사 분포, 환산 압력과 원본의 상변화 근사 |

전체 경로와 원본 해시로 프로그램을 구분한다. 다른 디렉터리의 같은 이름이나 기존 보충 그래프를 이번 25개에 포함하지 않는다. `src/native-light.json`은 각 원본의 대응 교재·입력 범위·시간 단위를 기록한다.

## 표현과 재생

도형은 GNU 파랑·회색을 기본으로 하며, 그래프·궤적 선의 불투명도는 0.65다. 스펙트럼의 실제 파장색은 선택해 볼 수 있다. 색 혼합 실험의 RGB와 흡수선의 검정은 실험 의미를 전달하는 물리적 색이다. 원본 로고·그림·랜덤 배경 장식은 새 도식으로 대체한다.

동작 장면·진행바·그래프·CSV는 같은 입력과 시간 상태를 사용한다. 진행바는 도식 아래에 배치하며 재생 버튼 문구가 바뀌어도 줄을 이동하지 않는다. 화면 밖/숨긴 탭에서는 재생을 멈추고, 입력 이벤트를 프레임당 묶으며 고정 곡선을 캐시한다. 터치·키보드·320/768/1360 px와 라이트/다크를 검사한다.

## 원본의 특성과 의도적인 차이

- 광선 작도는 각 원본의 선 생성 시점과 상 표시 순서를 보존하되 새 의미 도형으로 표현한다. 픽셀 일치 검사가 아니다.
- 두 확대경은 배율 +3/−3과 중심 205의 원본 변환식을 적용한다. 새 렌즈 이동 영역은 0–410이다. 원본의 무제한 화면 밖 끌기와 같은 입력 영역이라고 주장하지 않는다.
- 수소·헬륨·네온의 원본 파장 목록을 각각 사용한다. 원본의 분절 RGB 함수도 대조했으나 기본 화면은 테마색이다.
- 흑체 곡선은 원본 상수와 계산 단위를 사용한다. 자동 세로축과 선택 파장 수치는 새 학습용 표현이다.
- 반데르발스 도식의 평탄 압력은 원본의 온도별 선형 근사를 따른다. 엄밀한 Maxwell 등면적 구성으로 바꾸지 않았다.
- Fermat 실험의 61개 후보 중 원본은 기하학적 잔여거리 50의 경계로 경로를 선택한다. 새 그래프의 최소 도달시간 경로와 원본 선택 경로는 구분한다. `sqrt(x*x+y*y)`를 `hypot`로 바꾸면 경계에서 선택 단계가 달라지는 사례를 회귀 검사한다.
- 굴절 작도는 임계값을 포함하지만 원본 굴절 실험은 엄격한 부등식을 사용한다. 같은 임계각에서 결과가 달라지는 원본 분기를 남겼다.
- 길이 실험 `lengthcont`의 원본 표식 간격은 400(1−β²)이며 일반적인 고유길이/γ 설명과 혼동하지 않는다. β=0의 첫 표식 생성 시점도 보존한다.
- 빛시계는 이동 위치를 갱신한 뒤, 이전 시간값으로 펄스 위치를 계산하는 원본 순서를 따른다. 시계 바늘은 원본처럼 정수 초에서 갱신한다. 진행 구간과 그래프는 새 화면에 맞게 유한 범위로 정했다.
- 속도 슬라이더는 기본값과 0.99 같은 끝값이 HTML 눈금과 맞지 않아도 정확히 선택할 수 있게 하고, 입력을 원본 간격으로 양자화한다.
- 막대/헛간 원본은 100번 갱신 뒤 1틱을 건너뛴다. γ=1에서는 정지한다. 원본 클래스 슬라이더의 실제 간격은 0.05다.
- 움직이는 시계 배열의 원본 βx′/25 오프셋과 위치 순환을 보존한다. 추가 간격·사건 좌표·시간 수치는 교육용으로 표시한다.
- 원본의 별도 눈금자·축·기준계 표시 옵션을 새 통합 도식으로 재배치했다. 원본의 모든 버튼·임의 이벤트 순서와 시각적 동등성이 확보되었다는 뜻은 아니다.

## 검증을 구분해 기록

1. [원본 함수 대조](light-source-report.json): 25개, 1,870,771회. 비공개 원본 함수와 독립 계산을 비교하며, 선언된 단일 입력 눈금·광선 단계·시간 이력·파장을 검사한다. 최대 절대 오차 약 3.93×10⁻¹²다. 동시 슬라이더의 전체 곱집합을 검사한 기록은 아니다.
2. [실제 Ruffle 대조](light-runtime-report.json): 원본의 실제 기본/시간 수치, 목록에 기록한 슬라이더 최소·중간·최대 끌기, 확대경 끌기·스펙트럼 전환·일부 원본 재생 버튼을 검사한다. Flash 좌표의 twip 양자화와 배율 오차 허용치는 명시한다.
3. [새 HTML 조작](light-ui-report.json): 25개×3 화면 크기, 조작·유한 SVG·CSV·선 투명도·키보드·진행바 고정·끝에서 다시 재생·다크 모드를 검사한다.
4. [전체 HTML 재생](playback-ui-report.json): 기존 이식까지 포함한 실제 재생·정지·재개·끝에서 다시 재생을 별도로 검사한다.
5. [재생 시각 회귀](playback-clock-report.json): 쿨롱 모형에서 첫 RAF 시각이 재생 클릭보다 1–500 ms 앞설 때 단계를 −1로 떨어뜨리지 않고 정상 재생하는지 재현한다. 정상 시간에서 단독 재현이 통과해도 이 조건은 별도로 검사한다.

원본 실행·함수 대조·새 HTML UI 검사를 혼합해 전체 Flash의 모든 연속 입력·시간·이벤트 동등성 완료로 표시하지 않는다. 모든 보고서의 `fullEquivalence`는 false로 유지한다.
