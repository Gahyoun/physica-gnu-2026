## 표시와 조작

파랑·회색 SVG, 회색 용수철, 곡선 stroke-opacity0.65. graph는 동일 운동 상태에서 계산한다. 재생/정지 버튼은 실제 SVG 도형이 이동한 뒤 검사하며 프레임 수만 증가하는 것으로 합격시키지 않는다. 기본 빠르게와 느리게 옵션, 끝에서 즉시 처음으로 재생, 마지막 구간에서 반복 또는 정지, 하단의 고정된 진행 영역을 제공한다. 원본 시간과 계산 단계를 혼동하지 않도록 도식의 눈금과 원본 계산 시간에 별도 설명을 둔다. 화면 밖과 숨겨진 탭에서는 재생을 멈춘다.

원본의 무작위 시작 상태는 재현 가능한 시작값 또는 입력값으로 명시한다. 원본 랜덤 수열과 모든 입력·드래그의 직교 조합이 같다고 주장하지 않는다. 정지해 있던 원본 평형 실험에는 초기 변위·드래그를 제공하며 평형은 여전히 정적이다.

## 증거와 실행

- `tools/general-batch50b.test.mjs`: 외부 원본 캐시 없이 의미 있는 단위 검사9개.
- `tools/general-batch50b-source-check.mjs`: 원본 SHA256확인, 변경하지 않은 추출 함수의 VM실행값과 새 수치 모델 비교397,770건. 보고서의 파일별 scope가 정확한 범위다.
- `tools/general-batch50b-runtime-check.mjs`: 원본 SWF태그·스크립트·타이머를 보존하고 메모리상의 읽기 전용 관찰기를 추가한 실제 Ruffle 실행. 일부는 휴지 상태 또는 순수 함수에 한정되며 보고서에 이를 명시한다. 원본 전체 동등성·모든 입력 조합 검증을 완료했다고 주장하지 않는다.
- `tools/general-batch50b-browser-check.mjs`: 320/768/1360각 화면에서 입력 최소/최대/기본값, 실제 SVG움직임, 일시정지, 끝 재생, 유한 범위 정지, 빠르게/느리게, 현재 보이는 CSV, 드래그·줄 모드를 검사한다.
- `tools/general-batch50b-reading-check.mjs`: 별도 시험 화면과 별개로 실제 통합된 교재13개에서 자동 표시·움직임·정지·끝 재생·alpha값을 확인한다.

소스 캐시는 `PHYSICA_FLASH_SCRIPTS` 또는 ignored `preview/private-scripts`를 사용한다. 브라우저는 `PHYSICA_PLAYWRIGHT` 지정이 가능하고 로컬 원본 런타임은 `PHYSICA_BASE_URL`, 웹 검사는 `PHYSICA_PREVIEW_ORIGIN`을 사용한다. 소스·UI·런타임 JSON마다 현재 모델 SHA256을 기록한다. 원본 파일은 그대로 보존한다.

기본 재생 빈도는 원본 SWF의 frameRate 또는 명시된 Timer 간격에서 가져온다. 장면별 논리 계산 단계와 실제 브라우저 시간은 구별하며 독립 자식 타이머·부하 지연을 포함한 모든 벽시계 시간의 동등성을 주장하지 않는다. 느리게는 기본 빈도의 0.2배이다.
