# 박막의 반사·투과 표시 개선 · 2026-10-08

단층박막 `multilayer2.swf`를 원본 Ruffle에서 직접 실행했다. 루트는 1/1프레임이며, 화면은 두께·굴절률 입력과 파장별 반사율 그래프다. 시간 재생 모형이나 광원 그림이 아니다. 원본 6종의 수치·입력 대조는 [기존 런타임 기록](film-runtime-report.json)에 남겨 두었다.

큰 추가 도식 때문에 그래프가 아래로 밀리는 문제를 수정했다. 입력 다음에 현재 파장·반사율·투과율과 스펙트럼을 배치하고, 추가 도식에는 광원·입사·반사·투과 방향을 표시한다. 반사광 경로는 가독성을 위해 옆으로 분리하며, 화살표는 진행 방향이다. 반사·투과 비율은 정상 입사 행렬 계산의 현재값을 백분율로 표시한다.

원본에서 반사율을 그린 5종은 반사율, 간섭필터는 투과율이 기본이다. 반사율·투과율·둘 다 선택할 수 있으며, 작은 곡선이 보이도록 세로축 상한을 현재 표본에 맞춘다. 그래프 클릭·터치와 좌우 방향키(0.1 nm), Shift+방향키(10 nm), Home·End로 관측 파장을 고를 수 있다. CSV는 표시 선택에 관계없이 두 비율을 명시된 열 이름으로 저장한다.

계산식·원본 입력 범위·원본 SWF 바이트는 유지했다. 새 광원 도식과 투과율 보조 표시·자동 눈금은 리마스터의 표현이다. [화면 검사](film-ui-report.json)는 박막 6종, 135개 상태, 320·768·1360 화면과 라이트·다크에서 입력 적용·그래프 점·현재 수치·CSV를 확인한다. 모든 연속 입력 조합의 전수 대조를 뜻하지 않는다.

[18건 터치·입력 검사](film-touch-ui-report.json)는 박막 6종의 세 화면 크기에서 슬라이더 변경에 따른 곡선 변화, 실제 터치 좌표의 파장 선택, 초기화와 재생·프레임바 없음을 확인했다.
