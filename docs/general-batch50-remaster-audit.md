# 일반물리 10개 추가 복원 검토

대상은 `docs/parallel-remaster-batch50-01.json` 일반물리 10개입니다. 원본 그림 또는 프레임을 재생하지 않고 새로운 SVG 도형과 별도 계산 모델을 구현했습니다.

| 구분 | 파일 | source 비교 범위 | 실제 원본 관측 범위 |
|---|---:|---|---|
| 2·3차원 파동/막 진동 | 6 | 모든 원본 격자점, 각 스칼라 입력의 전체 눈금(다른 값은 기본값), 최소/최대 교차 조건, 5개 시간 단계, Bessel 30항 및 원본 근 표 | 실제 원본 AS3 timer에서 공개 격자 선택점, 실제 무작위 모드·파장 및 위상. 6개 모두 자연 시간 진행 관측 |
| 장벽/틈 회절 | 2 | 원본 Kirchhoff 이전 표본 sinc 적분, 정수 파장·틈 너비 전체 눈금, 광원/관측점 경계 입력, 최소/최대 교차 조건, 6개 세로 분포 모든 표본, 진폭·세기 모드 | 실제 원본 AS3 기본 입력의 수치 readout. 입력 조합 또는 원본 graphics 전체 대조는 아님 |
| 호이겐스/프레넬 | 2 | 원본 초기 파면·법선·경계·연결 판정·7분할 이동, 36개 파면의 모든 광선, 4개 이차 파면 반경, Fresnel 5개 재현 가능한 난수 시작값 | 실제 원본 AS3 자연 진행의 모든 35/100개 광선 위치·방향·경계·연결을 이전 관측 파면에서 다음 파면으로 대조. 원본 이차파면 graphics 자체는 미관측 |

수치 source 비교 총 13,696,370개이며 source 보고서 10개 모두 통과했습니다. source 함수를 별도 VM에서 실행한 결과와 실제 원본 runtime 관측 결과를 별개 보고서로 구분합니다. 런타임에 삽입한 것은 공개 값을 읽기만 하는 새 observer 클래스입니다. 원본 태그 순서·바이트와 ABC, 원본 문서 클래스·Timer는 보존하고 원본 SWF SHA256 재확인을 수행합니다.

## 구현과 표시

- 그래프와 파면 선의 실제 계산된 `stroke-opacity`는 0.65입니다. GNU 파랑과 회색만 사용합니다.
- 광원과 관측점을 드래그할 수 있으며 같은 조작을 키보드 range 입력으로도 수행할 수 있습니다. 정적 회절 모델에는 재생·프레임바가 없습니다.
- 파동과 호이겐스 모델은 빠른 원본 속도를 기본으로 하고 느리게 옵션을 제공합니다. 계산 단계는 그림 아래에 위치합니다. 끝에서 재생하면 즉시 0으로 돌아가며 유한 구간 밖으로 내부 단계가 증가하지 않습니다.
- 브라우저가 숨겨지거나 실험이 화면 밖으로 나가면 재생을 정지합니다. SVG 이동을 별도로 비교하여 숫자만 바뀌는 가짜 재생을 배제했습니다.
- 데이터 CSV는 클릭 직전 화면의 현재 입력·계산 단계와 대조합니다. 파동은 전체 격자, 회절은 6개 분포와 현재 관측점, 호이겐스는 현재 파면의 모든 광선을 저장합니다.
- 320/768/1360 화면 크기에서 입력 최소·최대·기본값, 실제 SVG 이동, 일시정지, 끝 재생, 반복 해제 끝 정지, 느린 재생, 현재 CSV, 정적 프레임바 부재를 확인했습니다. 768 화면에서 실제 교재 loader의 자동 연결·움직임·투명도도 확인합니다.

## 명시적인 원본과의 차이 및 한계

원본의 임의 초기 모드·파장은 재현 가능한 기본값과 직접 입력으로 드러냅니다. Fresnel은 원본 초기 파면 공식 그대로 재현 가능한 난수 시작값을 사용하고 새 파면 버튼으로 이를 변경하며 화면에 이 변경을 설명합니다. 해당 원본의 `InitWave`에서 임의 `wavelength` 변수는 `Prototype.wavelength`에 전달되지 않으므로 실제 전파 간격 20을 그대로 유지합니다.

원본 회절의 진폭 확인란은 실제 진폭을 계산하지만 수치 라벨에 I를 표시하며, 해제 상태의 세기는 A로 표시하는 뒤바뀐 라벨이 있습니다. 리마스터는 진폭 A/세기 I 라벨을 바로잡았습니다. 적분 자체와 유한 표본 간격은 원본을 유지하므로 정확한 연속 적분 또는 대칭성이 새로 보장된다고 주장하지 않습니다.

카메라·확대·파면 mesh/등고선의 시각 디자인은 새 SVG 표현입니다. 원본 모든 graphics 픽셀 및 음영·색상 동일성을 목표로 하지 않습니다. 재생·느린 속도·유한 구간 seek·반복·CSV는 현대 HTML 인터페이스입니다. 원본에서 자동 재생되던 실험도 리마스터는 사용자가 재생을 누릅니다.

연속 드래그 공간, 다중 입력 전체 Cartesian product, 무제한 임의 난수 이력과 모든 시간의 런타임 동등성을 입증한 것은 아닙니다. 각 보고서의 `fullEquivalence`는 false를 유지합니다.
