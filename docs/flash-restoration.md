# 원본 Flash 웹 복원

2026-10-05. 원저자 정기수 교수님. 원본은 [물리의 이해](http://physica.gnu.ac.kr/)다.

## 두 가지 재생 방식

사용자가 승인한 원본 웹 호환 재생과 HTML 재구현을 병행한다. **원본 웹 재생은 SWF의 동작·계산·그래프를 Ruffle 0.6.0에서 실행하는 방식**이다. 모든 원본을 SVG/JavaScript로 다시 작성했다는 뜻은 아니다. 원본 SWF는 출처와 SHA-256을 기록하고 바이트를 변경하지 않았다. 추출한 ActionScript와 원본 HTML 본문은 공개하지 않는다.

본문과 Flash XML 목록을 대조한 서로 다른 SWF 518개를 확보했다. `flashList.xml`의 517개 항목은 모두 대응 파일에 연결된다. 기존 Canvas·Java 애플릿·영상은 이 숫자에 포함하지 않는다. 대단원별 SWF: 힘과 운동 29, 파동 74, 열과 물질의 상태 12, 전기와 자기 36, 빛 202, 현대물리 146, 핵물리 19. 원본 파일 합계 10,091,762 bytes.

원본 그래프도 해당 SWF 안에서 함께 실행된다. 교재의 ‘원본 애니메이션’에서 열 수 있으며 자료 목록·찾아보기의 Flash 항목은 해당 재생 화면으로 연결된다. 별도 목록은 `flash.html`이다. 필요한 때만 엔진을 읽고 한 페이지에서는 한 원본만 열어 둔다. 일시정지는 그림·그래프·계산을 함께 멈추며 초기화는 원본 파일을 다시 불러온다. 화면 밖이나 숨겨진 탭에서는 멈춘다. 원본의 화면 색상은 유지한다.

## HTML 재구현과 그래프

`harmoniccircular.swf`를 JPEXS FFDec 26.3.0으로 분석하고 독립적인 HTML/SVG 코드로 작성했다. 교재 ‘조화진동 3쪽’에서 원본과 비교할 수 있다.

- 원본 A=20…100, 초기 75; ω=0.1…5, 간격 0.05, 초기 2; φ=−3.14…3.14, 초기 0을 따른다.
- 원본 x(t)=A sin(φ+ωt), 주기 2π/ω, 진동수 ω/(2π)를 따른다.
- 원운동과 수직 투영, 시간 그래프의 커서가 같은 시간·조절값을 사용한다.
- 진폭은 원본 눈금이며 확인하지 않은 길이 단위를 붙이지 않았다.
- 속도·가속도 그래프와 401개 시점의 CSV는 HTML 구현에서 추가했다.
- 0…20초를 시각화한다. 원본은 정수 주기에 맞춰 20초를 약간 넘는 시점에서 반복하고 HTML 구현은 20초에서 반복하므로 재생 시간 경계와 픽셀 배치는 동일하지 않다.

## 검증의 범위

`flash-browser-report.json`에서 518개 모두 로딩 완료·메타데이터·비어 있지 않은 화면을 확인했다. 요청 실패와 JavaScript 오류는 없었다. 초당 3프레임인 `calcite.swf`와 `nacl.swf`는 실제 그리기 프레임까지 기다려 재확인했다. 이 검사는 모든 원본의 슬라이더·버튼·계산값·탐구 절차를 끝까지 감수했다는 뜻이 아니다. 파일별 `controlsVerified`는 별도의 조작 대조 전까지 false로 남긴다.

대표적인 조화진동·감쇠진동 그래프·강제진동 그래프·파동·3차원 모드에서 열기·재생·일시정지·초기화·닫기를 확인했다. HTML 시간 그래프·CSV·320/768/1360px 화면과 다크 모드를 확인했다. 원본의 조화진동 동작 버튼과 진폭 조작에 따른 화면·그래프 갱신도 확인했다. 결과는 `flash-ui-report.json`에 기록한다. 순수 계산 테스트는 원본 400개 그래프 구간과 원운동 반지름, 미분 관계, 주기·진동수, 원본 파일의 해시와 헤더를 검사한다.

모든 SWF가 열린다는 사실만으로 원저자의 모든 계산과 교육적 내용을 현대 물리 기준으로 검증 완료했다고 표시하지 않는다. 개별 HTML 이식과 입력 경계·출력 수치의 대조 기록을 이어 간다.

- API·제약은 [공식 사용 문서](https://github.com/ruffle-rs/ruffle/wiki/Using-Ruffle)에 따른다. 원본의 외부 페이지 열기와 페이지 JavaScript 실행 권한은 허용하지 않고 계산·그리기·내부 데이터 재생을 제공한다.

### 차이를 숨기지 않는 복원

- `graph_damp`의 부족감쇠 분기는 초기 속도가 −b/2이고 다른 분기는 0이다. 기본 ‘원본 곡선의 초기조건’은 이 차이를 유지한다. 별도로 모든 영역에 x(0)=1,v(0)=0을 사용하는 모드를 제공한다. 원본 임계 분기의 정의되지 않은 `t`는 입력 시간으로 바로잡았으며 원본 SWF 자체는 변경하지 않았다. 독립 RK4 해와 에너지 감소, 임계점 연속성을 검증했다.
- `graph_driven`의 b=0,ω=10 반환값 100000은 발산점을 그리기 위한 표식이다. HTML에서는 진폭 ∞를 표시하고 초기 정지 해 x=5t sin(10t)를 사용한다. 다른 설정에서는 정상상태 운동을 표시하며 과도운동을 포함한 모의실험과 구별한다.
- `drivenosc2`는 질량 0.01, k=1이며 원본 코드의 감쇠항에 dx=0.01이 곱해진다. HTML에서는 이를 정규화한 운동식 x″+b x′+100x=−100sin(ωt)로 독립 구현했다. 그래프만으로 정상상태 진폭을 실시간 측정값으로 오인하지 않도록 서로 다른 색의 점을 사용한다. 측정은 원본과 같은 하위 단계의 방향 전환에서 이루어진다.
- HTML 추가 모의실험은 계산 시간을 20초까지 탐색할 수 있고 처음에는 일시정지한다. 원본의 자동 재생·2000프레임 반복·느리게 재생·원본 그래프 점 보관/연결·강제진동 지지점/질점 드래그 등 모든 조작을 그대로 옮긴 것은 아니다. 감쇠 모의실험의 초기화는 기본 설정과 초기 변위를 복구한다. 원본의 평형 상태 초기화와 구별된다. 이러한 차이 때문에 전체 조작 일치 완료로 표시하지 않는다.
- 속도·가속도·시간 탐색·CSV·리사이즈/다크 테마는 HTML 확장 기능이다. 그래프와 운동이 계산 상태를 공유하며 수치 모의실험에서는 커서·표시 시간·질점 모두 동일한 계산 단계에 맞춘다.

### 보충 탐구의 그래프 결합

원본 이식과 별개인 79개 보충 모형 중 조화진동·연결된 진동자·감쇠진동·운동량·충격량·방사성 붕괴·붕괴 계열은 운동 또는 평균 개체수 도식을 시간 그래프와 함께 제공한다. 진행파·반사파·정상파·위상 중첩은 기록점 좌표를 선택하면 그 지점의 시간 그래프를 같은 파동식으로 그린다. 시간축과 공간축을 혼합하지 않고 시간 탐색·일시정지·초기화를 공유한다. 붕괴 도식은 평균 개체수의 비율이며 개별 핵의 무작위 붕괴를 검증한 애니메이션이라고 표시하지 않는다.
