## 실행한 검증

- `node --test tools/legacy-general.test.mjs`: 27개 테스트 통과. 물리적 불변량, 계산 단계, 재현 가능한 초기배치, 입력 양 끝의 유한성 및 source-specific 수식을 검사했다.
- 원본 다운로드 Java bytecode의 실제 `d2wave3p.Bessel`, `d2wave3p.wave`, `resonan1.Wave`, `resonan1.PWave`를 JVM에서 직접 호출한 180개 수치(20+48+112)와 JS 계산이 일치했다. 원본 생성자의 AWT 화면 생성만 우회했으며 GUI 입력을 실행한 것은 아니다. 결과/해시는 `docs/legacy-general-original-oracle.json`에 기록했다. resonan1의 옛 LocalVariableTable 메타데이터 때문에 이 수치 전용 호출은 Java 11 `-Xverify:none`을 사용했다.
- `docs/legacy-general-ui-report.json`: 17개 실제 Chromium HTML UI에서 재생 후 상태 변경, 일시정지 후 고정, 모든 슬라이더의 최소/최대, seek 100, 초기화 0, 전체 상태 유한성 통과. 페이지 JS 오류 0. 결과는 원본 AWT가 아닌 리마스터 UI의 검사임을 명시했다.

연속적인 모든 입력 조합의 원본 GUI/영상 대조 완료를 주장하지 않는다. 원본 수치 메서드 대조와 현대 HTML UI 검증을 구분하고, 남은 원본 옵션은 위 표에 적었다. Java 애플릿은 최신 브라우저에서 실행되지 않으므로 원본 링크를 보존하고 실제 계산식을 바탕으로 이식했다.

추가된 StringMotion은 원본 0.001초 × 20 하위 적분, 장력 눈금 × 100, 중력 +9.8, 마찰 0.2를 사용한다. MembraneMotion은 0.0025초 × 20 하위 적분, 장력 500, 중력 −6, 마찰 0.1, 구동 힘 250 sin(2πft)을 사용한다. 열린 막의 평균 높이를 ±0.05 제한으로 보정하는 원본 코드도 보존했다. 장면은 DPR 상한 2의 Canvas, 물리 계산은 Float64Array로 원본의 이중정밀도와 1849질점 수를 유지했다.

`docs/legacy-general-field-ui-report.json`에서 StringMotion 선택 옵션 5개와 MembraneMotion 선택 옵션 9개, 두 장면의 직접 질점 끌기, 끌기 이후 실제 시간 진행을 추가 검증했다. 768px 태블릿과 375px 모바일 화면 캡처에서 조작/읽기 배치를 점검했다. 원형/사각·고정/열린 경계 조합은 수치 테스트에서도 검사했다.
