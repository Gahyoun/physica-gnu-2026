## 원본 계산과 추가 학습 기능

저항 원본의 세 전구를 저항 기호로 바꿨다. 두 회로의 ON/OFF 조합을 유지하고 전압·저항 입력, 등가 저항·전류·전력과 I–V 곡선을 추가했다. 추가 수치는 옴의 법칙과 키르히호프 법칙의 이상적 회로 계산이며 원본 전구의 밝기나 비선형 저항 측정값으로 주장하지 않는다.

축전기의 충전 진행은 원본 그림의 전환 비율이다. RC 지수 충전이나 충전 전류의 수치해석이 아니다. 용량·전압 입력과 등가 용량·전하 값은 추가 학습 기능이다. HTML의 공통 진행바는 스위치 변경 시 충전 구간을 다시 시작하므로, 원본 두 타임라인에 서로 다른 시각에 스위치를 조작하는 모든 비동기 이력과의 동등성은 아직 검증하지 않았다.

변압기의 원본 스위치 두 상태와 계기 방향을 유지했다. 이상적 `V₂ = 2V₁` 계산을 추가했으며 원본 계기의 실제 전압 눈금 보정이나 손실을 확인한 측정 모형은 아니다. 저항·변압기의 원본은 스위치 상태 그림이므로 불필요한 재생 버튼을 넣지 않았다.

자기장 속 전하는 원본 24 fps에서 프레임당 1° 회전을 따른다. HTML 좌표는 위쪽에서 시작하는 단위 원으로 정규화했으며 속도와 힘, 좌표 그래프는 같은 위상을 읽는다. 실험적 전하량·질량·자기장 수치의 복원으로 세지 않는다.

옴의 법칙 실험은 원본의 입자 250개, 가속 `vₓ += 5V/50`, 위치 적분, 격자 거리·산란 확률, 산란 후 운동 에너지 0.8배, 경계 반사와 출구 재주입을 유지했다. 11회 갱신마다 통과 입자로 전류를 측정하고 원본의 0.95/0.05 계기 평활, 측정 대기 50회, 측정 구간별 평활, 2501회 갱신의 자동 전압 증가 분기를 따른다. 자동 측정 버튼의 카운터 보존과 40→50 Hz 전환도 반영했다. 계기, I–V 측정점, 시간 그래프와 CSV는 같은 수치 상태를 읽는다.

HTML은 재현 가능한 난수 시드를 사용한다. 원본의 실제 Math.random 시퀀스와 확률적 궤적 전체가 동일하다는 뜻은 아니다. 원본 부동소수점 전압이 배열의 비정수 속성으로 기록되는 문제를 정규화해, HTML은 0.1 V 눈금의 정수 측정 빈을 쓴다. 원본은 이동 전 그림 좌표를 먼저 갱신하지만 HTML은 계산 후 상태를 그린다. 따라서 픽셀·렌더링 순서의 동일성은 주장하지 않는다.

되감기는 100단계 간격의 체크포인트에서 같은 난수 상태를 이어 계산한다. 매 프레임에 전자 250개의 전체 이력을 복사하지 않는다. 화면 밖에서는 재생을 멈추며 진행바는 장면 아래에 고정했다. HTML의 5000단계 재생 구간과 반복·초기화·CSV는 추가 기능이며, 원본 자동 측정의 전압 1–10 V 전체 장시간 실행을 실제 Ruffle에서 끝까지 대조한 것은 아니다.

## 검사 근거와 한계

[독립 원본 함수 대조](circuit-source-report.json)는 **46,213,768회**의 수치·분기 비교를 기록한다. 옴의 법칙은 전압 5값 × 산란 7값의 35개 조합, 각 1200회 갱신에서 전자 250개 전부의 위치·속도와 전류·측정 빈·난수 상태를 대조했다. 자동 측정은 별도 5100회, 두 계기 함수와 그래프 좌표도 비교했다. 최대 절대 오차는 약 2.22×10⁻¹⁶이다. 원본 함수는 공개 저장소 밖에서 읽고 독립 VM으로 실행하며 추출된 스크립트를 배포하지 않는다.

[원본 Ruffle 런타임 대조](circuit-runtime-report.json)는 **941회**의 관측 수치 비교와 실제 마우스 조작을 기록한다. 직렬·병렬의 네 ON/OFF 조합과 OFF 복귀, 축전기의 끝 프레임, 변압기 계기, 원운동의 연속 회전, 옴의 법칙 슬라이더 최소·중간·최대와 자동 측정 ON/OFF를 확인했다. 전압 중간 눈금은 실제 클릭 결과를 확인하며 보정한 시도 `[5.4, 5.6, 5.5]`도 기록한다. 옴의 법칙 입자는 충돌·재주입이 발생하지 않았음을 확인한 구간만 다음 상태와 비교하며 확률적 충돌 구간을 통과로 세지 않는다. 원본 복사 버튼은 클릭했지만 클립보드 내용은 검증하지 않았다.

[HTML 화면 검사](circuit-ui-report.json)는 320·768·1360 px의 **15개 화면**에서 입력 끝점, 스위치에 따른 그림 변화, 실제 입자 이동, 정지·끝 재생, 체크포인트 되감기의 재현성, 그래프·CSV·수치 상태 일치, 라이트/다크를 검사했다. 회로의 부품 사이를 가로지르는 우회선이나 전원 양극·음극을 연결하는 잘못된 배선이 없음을 기하 검사로 확인했다. 추가 물리 검사에서는 저항 회로의 전압·전류·전력 보존, 축전기의 전하·전압 관계, 원운동의 힘·속도 수직 관계를 확인한다.

누적 HTML 대응본은 **254/518개**, 개별 이식 대기는 **264개**다. 유한 검사 범위 밖의 모든 연속 입력과 이벤트 순서의 동등성을 완료로 표시하지 않는다. `fullEquivalence`는 계속 false다.
